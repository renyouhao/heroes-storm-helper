  1. 继续用原账户：升级后，已保存的阿里云账户照常保留，不会自动切到 DeepSeek；原有 Key 不需要重新申请。

DeepSeek 的上下文开关怎么选？

发送同会话最近 3 条原文默认开启。接收消息翻译时，最多附带当前消息之前的 3 条相关原文，用来帮助理解缩写和指代；只取同一对话，密语按联系人隔离，无法确认联系人时不拼接其他私聊。发送者用匿名编号表示，不上传真实昵称。

可取消勾选；已保存 DeepSeek 账户时，点保存上下文设置应用修改。手动输入中文的翻译不附带聊天历史。DeepSeek 使用非思考模式；它仍可能误解俚语或有歧义的短句，发送前请检查译文。附带历史会增加输入用量，关闭后只发送当前正文及必要翻译指令。

仅阿里云旧配置：可在阿里云表单主动选择导入本机旧 .env，文件上限 16 KiB，只填入本次 ID／Secret 输入框，不会自动连接；关闭后清空 Secret。正常启动不会自动读取该文件，DeepSeek 无需此步骤。

配置只需对应服务的个人密钥。不必填写“其他调用用量”或确认月度额度。DeepSeek 可按按钮查询 API 账户的总／赠送／充值余额；阿里云的免费字符额度和实际用量仍到官方控制台查看，详见第 11 节。
等结果后再修改或重试。处理中暂不能改字段。关闭会取消尚未完成的配置，已经完成的保存或删除不会撤销。切换失败时，助手保留原服务并暂停云翻译，不会自动改用另一家或恢复旧 Key 计费。取消未完成的切换后，想恢复原服务，请回到个人翻译账户 → 选原服务 → 使用已保存账户，等验证成功再用；单独打开“自动翻译”不能恢复已暂停的云请求。按提示的阶段检查 Key、余额、网络或本机保存权限；每次连接和重新连接的翻译测试都会调用所选云服务。

中文 build 98348 试用的面板数据已做只读核对，用户已确认前一修复包的天赋和统计能发到团队。本轮稳定性修复后的实机表现、乱斗连续多局、英文客户端和其他分辨率还需要实际验收。天赋短效果离线提供，不用翻译 Key，也不额外调用 AI。

任务层数与我方大招冷却

任务天赋继续双击同一格：我方、对方的任务天赋都可在原已选天赋格附带可信计数，例如“任务层数：0”。有限任务完成时说明“任务已完成”。真实进行中的零层有效；隐藏、不跟踪或无法确认的数值不当作零，也不用隐藏标签残留的旧数字。

基础任务看独立图标：例如阿尔萨斯“霜之哀伤的饥渴”不是某一级已选天赋格。中文名称目录现收录 16 个有明确 Face 和本地化来源的基础任务条目；精确名称未命中时，只有原生身份、玩家归属和数值仍通过校验，才显示“基础任务1／基础任务2”，不会猜技能名。

我方大招只说可信的 Tab 冷却显示：在同一 Tab 天赋页双击自己或队友的大招图标，只播报专用冷却标签可见且通过校验的正数，例如“冷却显示：38秒”。敌方大招不读取、不播报。游戏从两个时间通道选择这个显示，它可能是充能恢复计时。这个显示不证明大招当前不可用或充能耗尽，也不承诺倒数结束后就能释放；充能、重置和技能变体可能影响可用性。标签隐藏、空白或显示零不代表已就绪，也不猜剩余充能次数；猎空专用充能 UI 尚未验证，暂不支持。未选大招、绑定变化或状态未知时不发送。

同一大招的天赋图标与冷却层重合时，按已验证的玩家、技能及原生位置归为一个冷却目标，避免把同一图标误判为冲突目标。有可信正数时播报冷却；没有可信读数时不生成冷却消息，普通天赋仍按原规则处理。其他不同目标真正重叠时继续拒绝播报。

这套逻辑读取游戏公共 UI 结构和当前玩家绑定，不保存本机对象地址；版本或布局、身份发生变化时停止本次播报。0–15 解码负责定位玩家模型，任务和冷却还需各自核对图标与显示状态。并非所有增益叠层都由 Tab 任务图标暴露。

此前真实只读样本包含凯尔萨斯热能对流 0→2 层、敌方阿尔萨斯基础任务 6→8 层和我方大招 38／29 秒。v2.1 修复后，仅确认萨拉塔斯试用中 45 秒对应同一 R 的唯一冷却命中；最终聊天发送仍待用户反馈。这些记录不代表全部英雄、语言、分辨率或完整发送流程均已实测；16 条名称映射也不等于 16 英雄实机验收。

开启同一个诊断开关后，会记录任务状态和层数、大招显示秒数及拒绝原因，并包含 reader 离线回放帧；board_profile 标明任务／冷却适配方案，board_code_verified 为 1 表示六处原生 getter 代码校验通过，0 表示尚未通过，代码变化时返回未知。日志总上限仍为默认 100 MiB，也包含聊天原文和译文，分享前检查隐私。开发者可用 --component reader 重放 quest_progress 与 cooldown_display 判定，不恢复整个真实游戏 UI。

  1. 点主窗侧栏底部检查更新，再点页内更新界面的检查按钮。正常启动会后台检查一次；也可点页内按钮手动检查，仅打开界面不会额外发起检查。
  2. 有新版本时，先看说明，再点下载更新。下载失败可以重试；没有可信校验信息时，按提示到官方发行页手动下载。
  3. 下载校验成功，点重启并更新。助手会退出，升级程序备份并替换程序后重新打开；个人 Key、语言资料和设置保留。

10 · 有问题，先对照这里

有原文，没有中文翻译

先看“自动翻译”是否开启，再到个人翻译账户页确认当前服务已连接。仅选择服务卡片或填好 Key，还没有启用翻译；需要点连接或使用已保存账户，等到验证成功。切换失败或取消未完成的配置后，请回到个人翻译账户 → 选原服务 → 使用已保存账户，验证成功后恢复；只打开自动翻译不能恢复云请求。收到的文字也要在英文或韩文支持范围内；尚未配置云服务时，助手仍能接收原文。

提示找不到聊天／大厅消息没接上

确认游戏和助手都开着，频道先选“全部聊天”。在游戏里手动发一条普通团队、队伍或密语消息，等它连接，不需要特意再发第二条。0.3.10 已调整首句补收；如果还在用旧版，请先退出旧程序并打开新版。仍不行就到“设置 → 连接 → 手动重新连接”。如果之前停过采集，先点“恢复采集”。独立战网客户端里的聊天不在采集范围；游戏已覆盖或释放的记录也无法补回。

连接提示密钥验证失败

DeepSeek：确认选中的是 DeepSeek，填写的是开放平台完整 API Key，密钥没有被撤销，网络可访问官方 API。这里只需要一个 API Key，不填阿里云 ID／Secret或网页登录密码。

阿里云：核对 ID 和 Secret 是否来自同一把 Key，有无漏字符、多空格、Key 被禁用或删除，以及网络能否访问阿里云。Secret 丢失时到官网创建新 Key。根据窗口的阶段和固定错误提示排查，反馈时不要发送完整密钥。

密钥验证通过，翻译测试或保存阶段失败

DeepSeek：检查开放平台是否有可用于 API 的余额、服务是否受限，以及网络是否稳定。能登录官网不等于 API 翻译测试已经成功。

阿里云：检查机器翻译通用版是否开通，当前 RAM 用户是否有翻译权限，以及账户是否欠费或受限。

本机保存失败：检查当前 Windows 用户及用户数据目录写入权限。失败的切换不会自动改用另一家；修正后重试，或明确选回已保存账户并验证。每次翻译测试都会调用所选云服务。

账户页只显示两张服务卡片，或者找不到 DeepSeek

第一次还没有保存任何账户时，页面先请你选择 DeepSeek 或阿里云，选中后才显示对应输入框。已有阿里云账户的用户会保留原服务，可在管理账户里选择另一家，不会强制切换。

如果完全没有 DeepSeek 选项，请确认运行的是 v2.4（2.4.0）或更高版本；旧 v2.3 及此前对局日志诊断测试包没有这些入口。先退出旧助手，从本页上方下载并完整解压正式包，不要反复重填旧包里的阿里云字段。

DeepSeek 余额没更新，或者查询失败

先确认当前服务是已连接的 DeepSeek，再点查询账户余额。查询在后台进行，不会清空中文草稿或关闭快捷输入。失败时看余额区域的错误；显示的旧金额和更新时间属于上次成功查询，不代表刚刚刷新成功。余额不是剩余字符数，也不能直接换算成固定可翻译条数。

旧版本的用量文件需要处理吗？

不用处理。旧 usage.sqlite3 和 usage.sqlite3.initialized 保留原样，当前版本不读取、不新建、不迁移或修复；旧账本缺失或损坏不影响启动、配置或翻译。凭据、语言资料、偏好和日志继续使用原来的 HotsChatHelper 用户目录。

Ctrl+T 翻译了，游戏里却没发出去

它只帮你复制。请回到游戏打开聊天框，Ctrl+V 粘贴，再按 Enter 发送。输入法还在选字时，先确定汉字，再按一次 Enter 提交翻译。快捷键无反应可以从助手主界面的“快捷输入”按钮打开。

按 F8 没出现 s，或者连按没效果

确认使用 v2.1（程序 2.1.0），关闭助手输入条，松开所有修饰键，再回游戏单独按 F8；游戏聊天输入框无需关闭，开着时会输入所选动作的 S 或 Y、S。此前按过 Enter／Esc 也不影响这次启动；运行中按 Enter／Esc 会结束当前连按，松开后可再按 F8 重开。如果改过快捷键，按你保存的那个键。用下方“按 F8 取消”提示判断是否启动；没有提示或有提示但无输入／动作，可分别反馈这两种情况。

游戏里看不到译文，或者位置挡视线

先在主界面确认确实有新的译文。双屏时，到“偏好设置 → 游戏内 → 字幕显示器”选“主显示器”，点“移动到所选屏幕”；也可“保存并调整位置”后跨屏拖动。字幕显示时间较短，可在同页调整；用无边框窗口化。透明字幕模式主要显示文字，想要底色可改为半透明面板。

某个短词或俚语翻译不符合语境

先对照保留的原文。使用 DeepSeek 时，可在账户页启用发送同会话最近 3 条原文，帮助理解简称和指代；需要保存上下文设置后才生效。阿里云当前路线按单条正文翻译。上下文也不能保证消除歧义，陌生俚语、断句或反话仍可能误译。需要时选消息点重试所选，或切换到已保存的另一家做比较；重试和连接测试都会调用云服务。

怎么把日志发给开发者排查？

诊断默认关闭。打开设置 → 诊断 → 开启诊断日志，复现一次，再点导出诊断日志。后台完成后会显示已导出的 ZIP 路径，可以选中复制；检查文件后，由你附上出问题的大致时间并自行分享。开启后会记录聊天原文、译文及翻译、自动天赋和双击播报的复现输入与状态；仅一个开关，没有额外详细模式或十分钟到期。下次启动仍关闭，关闭后已有日志仍可导出。

默认日志总上限 100 MiB，滚动覆盖最旧文件、保留七天；队列过载、覆盖和截断会计数。已配置密钥递归脱敏，分享前检查其他聊天隐私；不要额外附带 .env、credentials.dpapi、deepseek.dpapi 或用户数据库。导出不调用云服务、不自动上传。开发者可离线重放录制的业务判断；缺失或截断的数据会标明不完整，不能保证还原真实游戏、驱动或云端故障。

表情为什么显示为 [表情]？

游戏的图片表情标签会统一显示成 [表情]，避免露出很长的资源路径。只有表情时不会请求云翻译；混合英文、韩文的文字继续正常翻译。普通 Unicode 表情照常显示。

解码已经补全，是否代表所有电脑都验证过？

自 v2.0 起对 build 98348 支持 0–15 全部 16 种模型解码，每种先核对对应计算代码指纹。2、5、8、11、14 额外读取动态 salt，这是游戏解码参数，不是阿里云密钥。读取后复核模式、表根、编码槽、所用 key 与 salt 指针和值；变化或缺失就停止本次辅助判断。

16 个算法完成了合成读取和 303,810 次独立原生指令对照；朋友机器并未逐个分支实测全部 16 种。若自动天赋和双击播报仍不生效，保留原语言、分辨率和缩放，在进局前开启诊断，复现后导出 ZIP，并附操作时间、游戏 build、对局和窗口模式。解码回放包含编码、所需 key／salt 和计算结果，不是完整内存转储；回放一致只表示相同输入能重现相同判断，不代表功能实际成功或云端、游戏环境被还原。

还是解决不了，应该怎么反馈？

说明助手版本、当前使用 DeepSeek 还是阿里云、是在大厅还是对局、做了什么、显示什么提示，以及是否改过快捷键。可先从设置 → 诊断导出日志；截图时遮住 API Key、AccessKey ID／Secret、账号信息、好友昵称和私人聊天，不要发送完整密钥。

游戏里能看到团队／征召团队消息、助手却没有原文？大厅队伍／密语与对局显示聊天独立采集，“等待对局聊天”不等于翻译服务失败。v2.4 修复已知显示历史格式对时间戳的强制依赖，并保留节点、历史链与频道校验。请在进局前开启“设置 → 诊断 → 开启诊断日志”，在相应【团队】或【征召团队】频道发一条 hello，确认游戏里可见，记下时间并导出 ZIP。不要只用密语代替测试。扫描摘要会记录读取进度、候选、拒绝原因及有／无时间戳解析检查计数；计数可能含重复轮询，不等于收到的消息条数。朋友机器的实际效果仍需新包复测。公开 v1.0 不支持这套诊断导出。

大厅队伍昵称偶尔“未知”？0.3.11 已补充同账号的昵称查找：好友关系暂不可读、或者名字只在上层记录里时，会尝试恢复合法昵称。实在无法确认身份或名字数据损坏时仍显示“发送者未知”，正文照常接收。后续新消息会重新查名，旧消息不会自动改名；反馈时说明是否刚组队、同一个人的后续发言有没有恢复，不用提供真实昵称或聊天内容。

11 · 费用和 Key，记住这几句话就够了

DeepSeek：在助手里查 API 账户余额

  1. 确认当前服务是已连接的 DeepSeek，进入偏好设置 → 连接或个人翻译账户页。
  2. 点查询账户余额。助手后台向 DeepSeek 官方余额接口查询，不会清空正在编辑的中文或关闭快捷输入。
  3. 按币种查看总余额、赠送余额、充值余额和更新时间；总余额已包含可用赠金和充值余额，不要再把三项相加。

启动时不自动刷新余额；连接验证也会调用余额接口。界面金额是上次成功查询的结果，查询失败不会把旧时间改成刚刚成功。账户有 CNY／USD 时分别展示，不自行换算汇率。余额不是剩余字符数，也不是月度免费额度。

模型调用按输入、输出及相应缓存用量计费；提示词和附带历史也属于输入。请在开放平台查看账单，按需充值。当前价格和权益以DeepSeek 官方计费说明及自己的账户为准。字段解释见官方余额文档。

阿里云：到控制台查免费字符额度与实际用量

  1. 当前服务为阿里云时，在偏好设置 → 连接点查询免费额度／用量，或在阿里云配置区点打开阿里云官方入口。
  2. 默认浏览器打开阿里云机器翻译控制台，登录自己的账号，查看该账号实际的免费字符权益、已用量和费用。

助手只提供控制台入口，不自动读取阿里云用量，也不建立本地月度账本或承诺统一免费额度。服务开通前看清账号实际权益和官方计费规则；不要把免费权益理解为永久免费。

请求队列、限流、缓存去重和暂停继续保留，但不能替代任一家服务的账单和费用管理。助手里的连接测试、重新连接测试、重试消息和实际翻译都会调用所选服务。

两家 Key 分开保存，消息发给当前选中的服务

阿里云和 DeepSeek 的凭据分开使用 Windows DPAPI 加密，保存在当前 Windows 用户下；在个人翻译账户中替换、切换或删除。删除当前服务的本机账户，不会删除另一家，也不会去官网撤销这把 Key。密钥泄露时，到对应官方 Key 管理页撤销旧 Key，再创建新 Key 并重新配置助手。

阿里云：上传当前待译正文，不把发送者昵称作为翻译字段上传。DeepSeek：上传当前正文和必要的翻译指令；默认附带最多 3 条匿名标识的同会话原文，可在账户页关闭，手动中文回复始终不附历史。匿名化的是发送者标识，正文仍按消息实际内容发送。

默认聊天列表保留本次运行最近 500 条，退出后清空；主动开启诊断后，日志会按诊断说明保存原文和译文。本文可离线阅读，不收集 Key，也没有可以填写真实 Key 的网页输入框；请不要把密钥写进点评或反馈。

管理入口：DeepSeek API Key 页面、阿里云 AccessKey 说明。

DeepSeek 的上下文开关怎么选？

发送同会话最近 3 条原文默认开启。接收消息翻译时，最多附带当前消息之前的 3 条相关原文，用来帮助理解缩写和指代；只取同一对话，密语按联系人隔离，无法确认联系人时不拼接其他私聊。发送者用匿名编号表示，不上传真实昵称。

可取消勾选；已保存 DeepSeek 账户时，点保存上下文设置应用修改。手动输入中文的翻译不附带聊天历史。DeepSeek 使用非思考模式；它仍可能误解俚语或有歧义的短句，发送前请检查译文。附带历史会增加输入用量，关闭后只发送当前正文及必要翻译指令。

仅阿里云旧配置：可在阿里云表单主动选择导入本机旧 .env，文件上限 16 KiB，只填入本次 ID／Secret 输入框，不会自动连接；关闭后清空 Secret。正常启动不会自动读取该文件，DeepSeek 无需此步骤。

配置只需对应服务的个人密钥。不必填写“其他调用用量”或确认月度额度。DeepSeek 可按按钮查询 API 账户的总／赠送／充值余额；阿里云的免费字符额度和实际用量仍到官方控制台查看，详见第 11 节。

等结果后再修改或重试。处理中暂不能改字段。关闭会取消尚未完成的配置，已经完成的保存或删除不会撤销。切换失败时，助手保留原服务并暂停云翻译，不会自动改用另一家或恢复旧 Key 计费。取消未完成的切换后，想恢复原服务，请回到个人翻译账户 → 选原服务 → 使用已保存账户，等验证成功再用；单独打开“自动翻译”不能恢复已暂停的云请求。按提示的阶段检查 Key、余额、网络或本机保存权限；每次连接和重新连接的翻译测试都会调用所选云服务。

A. 看英文、韩文的中文翻译

• 保持游戏和助手都开着，确认主界面“自动翻译”开关已开启，“频道”先选全部聊天。

• 等游戏里出现一条英文或韩文文字消息。不需要先发一句来“热身”，只发一句也可以等待它接上；新位置的自动定位仍可能需要一些时间。

• 在主界面的实时消息看原文和译文。游戏里也会短暂显示底部译文；想回看完整内容就切到主界面。

支持你在游戏聊天框里本来就能看到的团队、征召团队、队伍、密语、所有玩家消息；大厅队伍和密语也可接收。征召团队指选人／禁用英雄阶段的【征召团队】频道；“仅团队”包含普通团队与征召团队，也可选“仅征召团队”。v2.4 支持已知显示历史结构中有／无时间戳的格式，不要求打开游戏聊天时间显示；真实征召阶段格式仍需实机复测。换局、返回大厅时让助手保持打开即可，一般不用每把点重连。其他语言、纯中文和数字通常保留原文。

第一次连上时，会收哪些消息？
大厅队伍、密语：补收这次开启采集以后发出的消息，连接过程中发的第一句也会收。
试用和普通对局：首次找到一条新的聊天记录链时，最多补收该链最近 5 条，可能带上打开助手前的近几条；首次连上前已经连发超过 5 条时，更早的内容可能不在补收范围。之后按新消息继续，不会每次轮询都重翻这 5 条。已有记录位置的重连，也从未读处继续。

B. 用中文写，让助手帮你译成英语或韩语

Ctrl + T→输入中文、选语言→Enter 翻译→回游戏粘贴发送

• 在游戏里按 Ctrl+T，打开中文输入条。

• 输入想说的中文，例如“我们一起走”，选择英语或韩语。Ctrl+Tab 也能切换这两种语言。

• 按 Enter 或点翻译并复制。正在用中文输入法选字时，第一次 Enter 可能只是确定汉字；汉字确定后再按一次才提交。

• 成功后，助手会把译文复制好，输入条随后收起。回到游戏，按 Enter 打开游戏聊天框，Ctrl+V 粘贴 → 看一下频道和内容 → Enter 发送。

发送前最后一个 Enter 由你来按。助手负责翻译和复制，不会替你把话自动发出去。翻译时先等结果，别急着点到别的窗口；失去焦点会取消本次自动复制，文字仍保留，可以重新翻译。当前源码中，点一次输入条右上角关闭按钮或按 Esc 即可收起，草稿仍保留。

C. 快速选一句常用短句

先在主界面的常用短句中新增或收藏表达。打开 Ctrl+T 输入条，空输入时显示少量收藏项；输入中文后显示匹配候选。

Tab 先进入候选列表，方向键在候选内选择，再按 Tab 或用鼠标点击仅填入中文；检查文字和语言后，再按 Enter 翻译并复制。中文输入法选字时不接管这些候选快捷键，Ctrl+Tab 仍切换英语／韩语。

已校对、中文精确匹配，且当前语言只有唯一译文时，可以直接使用既有本机译文。未校对、缺少当前语言译文或存在冲突时仍需翻译。修改短句正文或译文后，请重新核对并勾选“已校对”。

07 · F8 动作连按

这个功能可重复按 S，或交替按 Y＋S，不需要翻译 Key。先在助手的“动作连按”页选择动作；S 和 Y＋S 的“按键间隔”都可填 20–5000 毫秒整数，分别保存，新配置均默认 20；旧版保存值保留，然后点击保存并应用。

• 启动助手正式程序，切回游戏。聊天输入框开着也可以，无需先关闭。

• 单独按 F8 开始已保存的动作。不用先去助手里点击“准备连按”；需要配合游戏动作时，自己右键点游戏地面。

• 如果 Y＋S 间隔填 200，就是 Y → 等 200 毫秒 → S → 等 200 毫秒再循环。S 模式也可以改间隔，例如填 100 就是每隔 100 毫秒按一次 S。保存新配置会结束当前动作，需回游戏再按 F8；实际节奏受系统与游戏响应影响，卡顿不补发。

• 看到游戏下方显示“正在连按 / 按 F8 取消”，就是本次连按的状态提示。

• 再按一次 F8 取消，提示会收起。之后想再开，松开按键后重新按 F8 就行。

Esc、Enter、打开 Ctrl+T、按组合键或切出游戏，也会结束本次。Esc／Enter 只结束当前连按，不会阻止你松开按键后下一次单独按 F8 重新开始；切回游戏不会自动继续。右键仍由你自己操作；动作连按和连续开箱不能同时运行。

聊天框开着时，S 或 Y＋S 会输入到聊天框。0.3.11 不再按是否打开聊天框或此前的 Enter／Esc 状态拦截 F8。可以用下方“按 F8 取消”提示判断是否启动，再按 F8 取消；如果要看游戏动作，再由自己关闭输入框并操作。连按按键效果由游戏决定，不保证提高攻击速度。

07B · 自动选爱心天赋

自 v2.0 起沿用 v1.2 加入的自动首选天赋；v1.0 及更早的包不包含。它不需要翻译 Key，默认关闭。

• 先在游戏里给各层想用的天赋标好爱心，选中自己要用的首选方案。

• 游戏内“快速选择首选天赋”快捷键保持为 Ctrl＋反引号。反引号在 Esc 下方、数字 1 左边。

• 助手打开天赋辅助，勾选“自动选择游戏内的爱心天赋”，再回游戏。开关会保存，下一局自动重新识别；不用每把准备。

• 天赋待选时，助手先按下 Ctrl 约 80 毫秒，再按住反引号约 80 毫秒后释放，让游戏先识别修饰键；发送主键前再次核验待选状态与前台。每层只尝试一次，然后回读确认该层是否选中。显示 3 秒未确认时，请检查爱心和快捷键，并手选本层；下一层会继续检测。反复关开开关不会重试本层。

切出游戏时不发按键，也不会抢焦点；后台低频只读，观察返回大厅或换局。使用开箱、连按或快捷输入期间延后。关闭开关后停止读取和发送。看不准自己的玩家身份、游戏版本或天赋状态时暂停。

实测范围要分开看：build 98348 的霍格、克罗米试用、大厅退出再进、镜像克罗米归属已核对；克罗米一级已实际自动选中，组合键时序修复后，第 2、3 层完成输入对照，第 4 至 7 层通过完整后台服务连续自动补选并回读确认。乱斗自然升级、连续多局和英文客户端还需要实机验证，观战／回放未验收。助手按各英雄真实天赋等级读取，50 毫秒是轮询目标，不保证同一帧选中。游戏中不可选的爱心天赋不会被替换成其他选项；回读只确认“该层已选择”，不独立核对当前爱心目标。

• 双击统计页里一个具体数字，就只说那一项。例如点英雄伤害，只发“【我方】玩家（安度因）｜英雄伤害：12,345”，不会顺带说死亡次数。

如果没发出来，请看助手“双击播报”页里的状态文字，这里会显示聊天框仍打开、正文未校验完整、操作取消或限频等具体原因，切回助手查看时会保留上次结果。如果文字留在框里，先按 Esc 关闭，再重新双击；若提示“消息可能已经发送”，先查聊天记录，避免重复。状态短暂读不清时会稍等再确认，不会重复输入或补发回车。需要排查时，开启“设置 → 诊断”，复现后导出日志；日志会记录发送阶段、错误码、耗时及回放需要的输入、状态和内容；分享前检查聊天隐私。最下方的大厅／对局文字只是聊天采集来源。Tab 没关就退出对局，也不会把旧目标带到下一局；新局重新打开 Tab 并双击即可。

中文 build 98348 试用的面板数据已做只读核对，用户已确认前一修复包的天赋和统计能发到团队。本轮稳定性修复后的实机表现、乱斗连续多局、英文客户端和其他分辨率还需要实际验收。天赋短效果离线提供，不用翻译 Key，也不额外调用 AI。

任务层数与我方大招冷却

任务天赋继续双击同一格：我方、对方的任务天赋都可在原已选天赋格附带可信计数，例如“任务层数：0”。有限任务完成时说明“任务已完成”。真实进行中的零层有效；隐藏、不跟踪或无法确认的数值不当作零，也不用隐藏标签残留的旧数字。

基础任务看独立图标：例如阿尔萨斯“霜之哀伤的饥渴”不是某一级已选天赋格。中文名称目录现收录 16 个有明确 Face 和本地化来源的基础任务条目；精确名称未命中时，只有原生身份、玩家归属和数值仍通过校验，才显示“基础任务1／基础任务2”，不会猜技能名。

我方大招只说可信的 Tab 冷却显示：在同一 Tab 天赋页双击自己或队友的大招图标，只播报专用冷却标签可见且通过校验的正数，例如“冷却显示：38秒”。敌方大招不读取、不播报。游戏从两个时间通道选择这个显示，它可能是充能恢复计时。这个显示不证明大招当前不可用或充能耗尽，也不承诺倒数结束后就能释放；充能、重置和技能变体可能影响可用性。标签隐藏、空白或显示零不代表已就绪，也不猜剩余充能次数；猎空专用充能 UI 尚未验证，暂不支持。未选大招、绑定变化或状态未知时不发送。

同一大招的天赋图标与冷却层重合时，按已验证的玩家、技能及原生位置归为一个冷却目标，避免把同一图标误判为冲突目标。有可信正数时播报冷却；没有可信读数时不生成冷却消息，普通天赋仍按原规则处理。其他不同目标真正重叠时继续拒绝播报。

这套逻辑读取游戏公共 UI 结构和当前玩家绑定，不保存本机对象地址；版本或布局、身份发生变化时停止本次播报。0–15 解码负责定位玩家模型，任务和冷却还需各自核对图标与显示状态。并非所有增益叠层都由 Tab 任务图标暴露。

此前真实只读样本包含凯尔萨斯热能对流 0→2 层、敌方阿尔萨斯基础任务 6→8 层和我方大招 38／29 秒。v2.1 修复后，仅确认萨拉塔斯试用中 45 秒对应同一 R 的唯一冷却命中；最终聊天发送仍待用户反馈。这些记录不代表全部英雄、语言、分辨率或完整发送流程均已实测；16 条名称映射也不等于 16 英雄实机验收。

开启同一个诊断开关后，会记录任务状态和层数、大招显示秒数及拒绝原因，并包含 reader 离线回放帧；board_profile 标明任务／冷却适配方案，board_code_verified 为 1 表示六处原生 getter 代码校验通过，0 表示尚未通过，代码变化时返回未知。日志总上限仍为默认 100 MiB，也包含聊天原文和译文，分享前检查隐私。开发者可用 --component reader 重放 quest_progress 与 cooldown_display 判定，不恢复整个真实游戏 UI。

07D · 有新版本时怎么升级

如果正在使用 1.1.0 本地包，旧更新器只识别中文 ZIP 名，无法匹配新的 GitHub ASCII 附件；请手动下载 HotsHelper-2.4.0-Windows-x64.zip，先退出旧助手，再解压启动新版。本机 Key、语言资料和偏好仍在原用户目录，不用搬动。1.2.0 起的更新器支持 HotsHelper-<版本>-Windows-x64.zip 命名。 打开 v2.4 发行页（https://github.com/renyouhao/heroes-storm-helper/releases/tag/v2.4）。

• 点主窗侧栏底部检查更新，再点页内更新界面的检查按钮。正常启动会后台检查一次；也可点页内按钮手动检查，仅打开界面不会额外发起检查。
• 有新版本时，先看说明，再点下载更新。下载失败可以重试；没有可信校验信息时，按提示到官方发行页手动下载。
• 下载校验成功，点重启并更新。助手会退出，升级程序备份并替换程序后重新打开；个人 Key、语言资料和设置保留。

v2.4 正常启动会后台检查一次，也支持手动检查；确认有可用新版本后，“检查更新”旁显示提示点。尚未确认新版时不显示；已确认新版后的临时网络失败或取消不会清除提示点，下载完成但尚未安装时仍保留。发布说明按标题、段落和列表排版，文字随说明区宽度自动换行；调整主窗口长宽时，页内说明区自适应排版，长内容可滚动阅读。上述界面细节以包含这些改动的构建为准。

保留整个程序文件夹，把它放在自己有写入权限的普通目录。从源码运行时只能检查和下载；更新页里的 ZIP 路径可以选中复制，关闭助手或重新检查会清理未安装的暂存包。升级失败会尝试恢复旧程序。此机制的临时目录替换与回滚已测试，真实发行 EXE 跨版本升级仍待验收。

10 · 有问题，先对照这里

有原文，没有中文翻译

先看“自动翻译”是否开启，再到个人翻译账户页确认当前服务已连接。仅选择服务卡片或填好 Key，还没有启用翻译；需要点连接或使用已保存账户，等到验证成功。切换失败或取消未完成的配置后，请回到个人翻译账户 → 选原服务 → 使用已保存账户，验证成功后恢复；只打开自动翻译不能恢复云请求。收到的文字也要在英文或韩文支持范围内；尚未配置云服务时，助手仍能接收原文。

提示找不到聊天／大厅消息没接上

确认游戏和助手都开着，频道先选“全部聊天”。在游戏里手动发一条普通团队、队伍或密语消息，等它连接，不需要特意再发第二条。0.3.10 已调整首句补收；如果还在用旧版，请先退出旧程序并打开新版。仍不行就到“设置 → 连接 → 手动重新连接”。如果之前停过采集，先点“恢复采集”。独立战网客户端里的聊天不在采集范围；游戏已覆盖或释放的记录也无法补回。

连接提示密钥验证失败

DeepSeek：确认选中的是 DeepSeek，填写的是开放平台完整 API Key，密钥没有被撤销，网络可访问官方 API。这里只需要一个 API Key，不填阿里云 ID／Secret或网页登录密码。

阿里云：核对 ID 和 Secret 是否来自同一把 Key，有无漏字符、多空格、Key 被禁用或删除，以及网络能否访问阿里云。Secret 丢失时到官网创建新 Key。根据窗口的阶段和固定错误提示排查，反馈时不要发送完整密钥。

密钥验证通过，翻译测试或保存阶段失败

DeepSeek：检查开放平台是否有可用于 API 的余额、服务是否受限，以及网络是否稳定。能登录官网不等于 API 翻译测试已经成功。

阿里云：检查机器翻译通用版是否开通，当前 RAM 用户是否有翻译权限，以及账户是否欠费或受限。

本机保存失败：检查当前 Windows 用户及用户数据目录写入权限。失败的切换不会自动改用另一家；修正后重试，或明确选回已保存账户并验证。每次翻译测试都会调用所选云服务。

账户页只显示两张服务卡片，或者找不到 DeepSeek

第一次还没有保存任何账户时，页面先请你选择 DeepSeek 或阿里云，选中后才显示对应输入框。已有阿里云账户的用户会保留原服务，可在管理账户里选择另一家，不会强制切换。

如果完全没有 DeepSeek 选项，请确认运行的是 v2.4（2.4.0）或更高版本；旧 v2.3 及此前对局日志诊断测试包没有这些入口。先退出旧助手，从本页上方下载并完整解压正式包，不要反复重填旧包里的阿里云字段。

DeepSeek 余额没更新，或者查询失败

先确认当前服务是已连接的 DeepSeek，再点查询账户余额。查询在后台进行，不会清空中文草稿或关闭快捷输入。失败时看余额区域的错误；显示的旧金额和更新时间属于上次成功查询，不代表刚刚刷新成功。余额不是剩余字符数，也不能直接换算成固定可翻译条数。

旧版本的用量文件需要处理吗？

不用处理。旧 usage.sqlite3 和 usage.sqlite3.initialized 保留原样，当前版本不读取、不新建、不迁移或修复；旧账本缺失或损坏不影响启动、配置或翻译。凭据、语言资料、偏好和日志继续使用原来的 HotsChatHelper 用户目录。

Ctrl+T 翻译了，游戏里却没发出去

它只帮你复制。请回到游戏打开聊天框，Ctrl+V 粘贴，再按 Enter 发送。输入法还在选字时，先确定汉字，再按一次 Enter 提交翻译。快捷键无反应可以从助手主界面的“快捷输入”按钮打开。

按 F8 没出现 s，或者连按没效果

确认使用 v2.1（程序 2.1.0），关闭助手输入条，松开所有修饰键，再回游戏单独按 F8；游戏聊天输入框无需关闭，开着时会输入所选动作的 S 或 Y、S。此前按过 Enter／Esc 也不影响这次启动；运行中按 Enter／Esc 会结束当前连按，松开后可再按 F8 重开。如果改过快捷键，按你保存的那个键。用下方“按 F8 取消”提示判断是否启动；没有提示或有提示但无输入／动作，可分别反馈这两种情况。

游戏里看不到译文，或者位置挡视线

先在主界面确认确实有新的译文。双屏时，到“偏好设置 → 游戏内 → 字幕显示器”选“主显示器”，点“移动到所选屏幕”；也可“保存并调整位置”后跨屏拖动。字幕显示时间较短，可在同页调整；用无边框窗口化。透明字幕模式主要显示文字，想要底色可改为半透明面板。

某个短词或俚语翻译不符合语境

先对照保留的原文。使用 DeepSeek 时，可在账户页启用发送同会话最近 3 条原文，帮助理解简称和指代；需要保存上下文设置后才生效。阿里云当前路线按单条正文翻译。上下文也不能保证消除歧义，陌生俚语、断句或反话仍可能误译。需要时选消息点重试所选，或切换到已保存的另一家做比较；重试和连接测试都会调用云服务。

怎么把日志发给开发者排查？

诊断默认关闭。打开设置 → 诊断 → 开启诊断日志，复现一次，再点导出诊断日志。后台完成后会显示已导出的 ZIP 路径，可以选中复制；检查文件后，由你附上出问题的大致时间并自行分享。开启后会记录聊天原文、译文及翻译、自动天赋和双击播报的复现输入与状态；仅一个开关，没有额外详细模式或十分钟到期。下次启动仍关闭，关闭后已有日志仍可导出。

默认日志总上限 100 MiB，滚动覆盖最旧文件、保留七天；队列过载、覆盖和截断会计数。已配置密钥递归脱敏，分享前检查其他聊天隐私；不要额外附带 .env、credentials.dpapi、deepseek.dpapi 或用户数据库。导出不调用云服务、不自动上传。开发者可离线重放录制的业务判断；缺失或截断的数据会标明不完整，不能保证还原真实游戏、驱动或云端故障。

表情为什么显示为 [表情]？

游戏的图片表情标签会统一显示成 [表情]，避免露出很长的资源路径。只有表情时不会请求云翻译；混合英文、韩文的文字继续正常翻译。普通 Unicode 表情照常显示。

解码已经补全，是否代表所有电脑都验证过？

自 v2.0 起对 build 98348 支持 0–15 全部 16 种模型解码，每种先核对对应计算代码指纹。2、5、8、11、14 额外读取动态 salt，这是游戏解码参数，不是阿里云密钥。读取后复核模式、表根、编码槽、所用 key 与 salt 指针和值；变化或缺失就停止本次辅助判断。

16 个算法完成了合成读取和 303,810 次独立原生指令对照；朋友机器并未逐个分支实测全部 16 种。若自动天赋和双击播报仍不生效，保留原语言、分辨率和缩放，在进局前开启诊断，复现后导出 ZIP，并附操作时间、游戏 build、对局和窗口模式。解码回放包含编码、所需 key／salt 和计算结果，不是完整内存转储；回放一致只表示相同输入能重现相同判断，不代表功能实际成功或云端、游戏环境被还原。

还是解决不了，应该怎么反馈？

说明助手版本、当前使用 DeepSeek 还是阿里云、是在大厅还是对局、做了什么、显示什么提示，以及是否改过快捷键。可先从设置 → 诊断导出日志；截图时遮住 API Key、AccessKey ID／Secret、账号信息、好友昵称和私人聊天，不要发送完整密钥。

游戏里能看到团队／征召团队消息、助手却没有原文？大厅队伍／密语与对局显示聊天独立采集，“等待对局聊天”不等于翻译服务失败。v2.4 修复已知显示历史格式对时间戳的强制依赖，并保留节点、历史链与频道校验。请在进局前开启“设置 → 诊断 → 开启诊断日志”，在相应【团队】或【征召团队】频道发一条 hello，确认游戏里可见，记下时间并导出 ZIP。不要只用密语代替测试。扫描摘要会记录读取进度、候选、拒绝原因及有／无时间戳解析检查计数；计数可能含重复轮询，不等于收到的消息条数。朋友机器的实际效果仍需新包复测。公开 v1.0 不支持这套诊断导出。

大厅队伍昵称偶尔“未知”？0.3.11 已补充同账号的昵称查找：好友关系暂不可读、或者名字只在上层记录里时，会尝试恢复合法昵称。实在无法确认身份或名字数据损坏时仍显示“发送者未知”，正文照常接收。后续新消息会重新查名，旧消息不会自动改名；反馈时说明是否刚组队、同一个人的后续发言有没有恢复，不用提供真实昵称或聊天内容。

11 · 费用和 Key，记住这几句话就够了

DeepSeek：在助手里查 API 账户余额

• 确认当前服务是已连接的 DeepSeek，进入偏好设置 → 连接或个人翻译账户页。
• 点查询账户余额。助手后台向 DeepSeek 官方余额接口查询，不会清空正在编辑的中文或关闭快捷输入。
• 按币种查看总余额、赠送余额、充值余额和更新时间；总余额已包含可用赠金和充值余额，不要再把三项相加。

启动时不自动刷新余额；连接验证也会调用余额接口。界面金额是上次成功查询的结果，查询失败不会把旧时间改成刚刚成功。账户有 CNY／USD 时分别展示，不自行换算汇率。余额不是剩余字符数，也不是月度免费额度。

模型调用按输入、输出及相应缓存用量计费；提示词和附带历史也属于输入。请在开放平台查看账单，按需充值。当前价格和权益以DeepSeek 官方计费说明（https://api-docs.deepseek.com/zh-cn/quick_start/pricing/）及自己的账户为准。字段解释见官方余额文档（https://api-docs.deepseek.com/zh-cn/api/get-user-balance/）。

阿里云：到控制台查免费字符额度与实际用量

• 当前服务为阿里云时，在偏好设置 → 连接点查询免费额度／用量，或在阿里云配置区点打开阿里云官方入口。
• 默认浏览器打开阿里云机器翻译控制台（https://mt.console.aliyun.com/service），登录自己的账号，查看该账号实际的免费字符权益、已用量和费用。

助手只提供控制台入口，不自动读取阿里云用量，也不建立本地月度账本或承诺统一免费额度。服务开通前看清账号实际权益和官方计费规则（https://help.aliyun.com/zh/machine-translation/product-overview/billing-overview）；不要把免费权益理解为永久免费。

请求队列、限流、缓存去重和暂停继续保留，但不能替代任一家服务的账单和费用管理。助手里的连接测试、重新连接测试、重试消息和实际翻译都会调用所选服务。

两家 Key 分开保存，消息发给当前选中的服务

阿里云和 DeepSeek 的凭据分开使用 Windows DPAPI 加密，保存在当前 Windows 用户下；在个人翻译账户中替换、切换或删除。删除当前服务的本机账户，不会删除另一家，也不会去官网撤销这把 Key。密钥泄露时，到对应官方 Key 管理页撤销旧 Key，再创建新 Key 并重新配置助手。

复制给自己，或者发给新用户

先打开助手，再回游戏。
当前正式版：v2.4（2.4.0），包含双服务选择、DeepSeek、英文播报和多屏字幕。完整包：https://github.com/renyouhao/heroes-storm-helper/releases/download/v2.4/HotsHelper-2.4.0-Windows-x64.zip；校验与发行说明：https://github.com/renyouhao/heroes-storm-helper/releases/tag/v2.4。旧 EXE 不会因更新指南获得这些功能。
看翻译：自动翻译勾上，频道先选“全部聊天”，等新的英文／韩文消息。
首次配置：无已存账户时先看到两张卡片、不预选 → 选择一家服务，也可先关闭看原文。
DeepSeek：打开官方入口 → 登录并创建 API Key → 余额不足时按需充值 → 回助手只填 API Key → 连接并开始使用。
阿里云：开通机器翻译通用版 → 创建 RAM 用户并授权 → 回助手填 AccessKey ID / Secret → 连接并开始使用。
老用户：原阿里云账户继续保留；选另一家只是切表单，连接或“使用已保存账户”验证成功后才激活。重启记住成功选中的服务，可切回。
DeepSeek 上下文：默认最多附带同会话前 3 条匿名标识原文，可关；手动中文翻译无历史，思考模式关闭。
发消息：Ctrl+T → 写中文并选语言 → Enter 翻译 → 回游戏 Enter 打开聊天 → Ctrl+V → Enter 发送。
常用短句：空输入看收藏，输入中文查匹配 → Tab 进入候选，方向键选择 → Tab／鼠标只填字 → Enter 翻译并复制。
动作连按：先选 S 或 Y＋S，填间隔并保存应用 → 游戏前台 F8 开始 → 再 F8 取消。聊天框开着会输入对应按键；Esc／Enter 结束本次后，新按 F8 可重开。右键点地面由自己操作。
开补给箱：助手点“准备开箱” → 回游戏打开补给箱页 → 空格开始／暂停／继续 → Esc 结束。
更换或删除 Key：偏好设置 → 连接 → 管理账户。
查费用：DeepSeek 点“查询账户余额”，后台看总／赠送／充值余额和上次成功时间；阿里云点“查询免费额度／用量”，到官方控制台看字符权益和账单。
切换失败不自动改用另一家；取消未完成配置后保持暂停。恢复：个人翻译账户 → 选原服务 → 使用已保存账户 → 等验证成功；只打开自动翻译不能恢复云请求。
两家 Key 分开加密保存；删除当前本机账户不影响另一家，也不会在官网撤销 Key。截图和反馈不带密钥。

01 · 先准备好这几样

  1. 一台 Windows 64 位电脑，以及完整的助手压缩包。从发行页附件下载 HotsHelper-1.3.0-Windows-x64.zip，解压到一个普通文件夹里，再打开里面的“风暴英雄助手.exe”。整个文件夹都要保留，不要只把 exe 单独拖出来；不用另外安装 Python 或 SDK。助手会自动创建自己的配置目录，不用拷贝 AppData。更新时先正常退出旧助手，再启动新文件夹里的程序。
  2. 自己的阿里云账号。浏览器打开阿里云官网，注册或登录。网页如果要求身份认证，按它的提示完成。申请和开通服务都由你在官网操作。
  3. 能上网的网络和《风暴英雄》。云翻译需要网络；助手目前适配中文客户端 build 98348。建议游戏用“无边框窗口化”，方便显示游戏内提示。

02 · 在阿里云开通“机器翻译通用版”

这一步在浏览器里操作

  1. 登录阿里云后，在产品搜索里输入“机器翻译”。也可以从机器翻译官方产品页进入控制台。
  2. 找到通用版翻译引擎／机器翻译通用版，选择开通，按页面提示完成。助手用的是这个文本翻译服务。
  3. 确认控制台显示该服务已经开通。看到资源包、购买或支付页面时，先看清免费额度、价格和你要买的内容，再决定是否继续；本文不要求你购买资源包。
检查一下：现在是“翻译服务已开通”。接下来还要创建 Key 并添加权限，光完成这一步还不能让助手翻译。

页面叫法可能调整，认准“机器翻译”和“通用版”。官方开通步骤

03 · 给助手申请一把专用 Key

推荐给助手建一个单独的 RAM 用户。大白话就是：给助手一把专门做翻译的“副钥匙”，而不是把整个阿里云账号的“大钥匙”交出去。

继续在浏览器里，用你自己的阿里云主账号操作

  1. 打开RAM 访问控制台，左侧选择身份管理 → 用户 → 创建用户。
  2. “登录名称”可以填 hots-helper；“显示名称”可以填“风暴英雄助手”。如果名称已被用过，换一个名称即可。
  3. 在“访问方式”里选择使用永久 AccessKey 访问；部分页面也可能写“OpenAPI 调用访问”。这是给软件使用的，通常不需要再为这个用户开“控制台访问”或设置网页登录密码。读完创建提示后确认创建。
  4. 创建成功后，保存 AccessKey ID 和 AccessKey Secret。如果创建时没有显示 Key，点进这个用户，找凭证管理 → AccessKey → 创建 AccessKey，再按提示完成验证。
Secret 一般只显示这一次。关掉前先保存到自己的密码管理器等私密位置。不要发到群里、截图教程里或文档点评区；如果丢了，要重新创建 Key。

新建 RAM 用户本身不收费，调用翻译服务按其计费规则计算。参考：创建 RAM 用户、创建 AccessKey。

04 · 告诉阿里云：“允许这把 Key 做文字翻译”

刚创建的 RAM 用户还没有翻译权限。这里按“只给文字翻译权限”的办法做一次，下面这段内容不用看懂，完整复制即可。

  1. 在 RAM 控制台左侧找到权限管理 → 权限策略 → 创建权限策略，切到脚本编辑。
  2. 把编辑框原来的内容全部替换成下面这段。点击确定或“继续编辑基本信息”，策略名称填写 HotsTextTranslateOnly，备注可不填，然后保存。

要复制的权限内容

{
  "Version": "1",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "alimt:TranslateGeneral"
      ],
      "Resource": "*"
    }
  ]
}
  1. 回到身份管理 → 用户，找到刚才的 hots-helper，点击添加权限。
  2. 选择自定义策略，搜 HotsTextTranslateOnly 并勾选。若出现“资源范围”，选择整个云账号，再点确认新增授权。
  3. 看到用户权限列表里有这条策略，就完成了。保存 Key 后不需要把阿里云网页登录密码填进助手。

这段策略只允许调用通用版文字翻译。你不需要把自己的账号 ID、AccessKey ID 或 Secret 填进这段权限内容。

授权依据：机器翻译子账号授权；网页操作：创建自定义策略、给 RAM 用户添加权限。

如果已经加过机器翻译权限，还要再做一次吗？

如果这个 RAM 用户已经有 AliyunMTFullAccess，它也包含助手需要的文字翻译权限，可以直接进入下一步。它允许管理整个机器翻译服务，范围比上面的专用策略更大；上面的方法更适合只给这个助手使用。系统策略官方说明

05 · 填好 Key，点一次“连接并开始使用”

这一步开始，在风暴英雄助手里操作

  1. 打开“风暴英雄助手.exe”。第一次会出现“配置自己的阿里云翻译”窗口。没出现也没关系，从主界面进入设置／偏好设置 → 连接 → 个人阿里云密钥。
  2. 把两段 Key 分别粘贴进 AccessKey ID 和 AccessKey Secret，别填反，前后也不要多出空格。
  3. 点击一次“连接并开始使用”，等待完成。助手会自动验证密钥所属主账号，再测试翻译“你好”；成功后使用 DPAPI 加密保存凭据并启用翻译。首次不必分开点击验证和保存。
  4. 看到配置成功和测试译文后，回到助手即可使用。Key 已加密保存在当前 Windows 用户下，之后通常不用每次重填。

06 · 看别人说什么，发出自己想说的话

A. 看英文、韩文的中文翻译

  1. 保持游戏和助手都开着，确认主界面“自动翻译”已勾选，“频道”先选全部聊天。
  2. 等游戏里出现一条英文或韩文文字消息。不需要先发一句来“热身”，只发一句也可以等待它接上；新位置的自动定位仍可能需要一些时间。
  3. 在主界面的实时消息看原文和译文。游戏里也会短暂显示底部译文；想回看完整内容就切到主界面。

支持你在游戏聊天框里本来就能看到的团队、队伍、密语、所有玩家消息；大厅队伍和密语也可接收。换局、返回大厅时让助手保持打开即可，一般不用每把点重连。中文消息及纯数字、符号、表情只显示原文，不附“不支持”“无需翻译”或“未翻译”状态；真正不支持的语言保留原因，英文与韩文照常翻译。

第一次连上时，会收哪些消息？
大厅队伍、密语：补收这次开启采集以后发出的消息，连接过程中发的第一句也会收。
试用和普通对局：首次找到一条新的聊天记录链时，最多补收该链最近 5 条，可能带上打开助手前的近几条；首次连上前已经连发超过 5 条时，更早的内容可能不在补收范围。之后按新消息继续，不会每次轮询都重翻这 5 条。已有记录位置的重连，也从未读处继续。
v1.3 消息状态含义和处理
中文、纯数字／符号／表情仅显示原文，不附翻译状态，也不调用云翻译。
排队中 / 翻译中请求等待处理或正在翻译，可以先等结果。
跳过并说明原因需要翻译的消息遇到服务未配置、配置处理中、云翻译已关闭、自动翻译已暂停时保留原因；真正不支持的语言也说明原因。中文及纯数字、符号、表情只显示原文。
翻译失败 / 防刷屏已暂缓失败可查看具体提示再“重试所选”；防刷屏不删除原文。手动重试可能调用云服务。
v1.3 给迟到译文留出阅读时间。默认15秒新鲜窗口内获准展示的译文，会获得至少3秒实际阅读时间；新的原文不会立即抢走正在看的译文。较长停留设置会相应延长有界新鲜窗口。过期旧消息不复活，换局或关闭字幕会清理；Ctrl+T 打开时暂藏字幕，收起后只恢复未过期内容，不因隐藏续期。完整历史仍可在主界面查看。

B. 用中文写，让助手帮你译成英语或韩语

Ctrl + T→输入中文、选语言→Enter 翻译→回游戏粘贴发送
  1. 在游戏里按 Ctrl+T，打开中文输入条。v1.3 同步采用圆角控件，保持深色高对比。
  2. 输入想说的中文，例如“我们一起走”，选择英语或韩语。Ctrl+Tab 也能切换这两种语言。
  3. 按 Enter 或点翻译并复制。正在用中文输入法选字时，第一次 Enter 可能只是确定汉字；汉字确定后再按一次才提交。
  4. 成功后，助手会把译文复制好，输入条随后收起。回到游戏，按 Enter 打开游戏聊天框，Ctrl+V 粘贴 → 看一下频道和内容 → Enter 发送。
发送前最后一个 Enter 由你来按。助手负责翻译和复制，不会替你把话自动发出去。翻译时先等结果，别急着点到别的窗口；失去焦点会取消本次自动复制，文字仍保留，可以重新翻译。输入条里按 Esc 可以取消。

07 · F8 动作连按

这个功能可重复按 S，或交替按 Y＋S，不需要翻译 Key。先在助手的“动作连按”页选择动作；S 和 Y＋S 的“按键间隔”都可填 20–5000 毫秒整数，分别保存，新配置均默认 20；旧版保存值保留，然后点击保存并应用。

  1. 启动助手正式程序，切回游戏。聊天输入框开着也可以，无需先关闭。
  2. 单独按 F8 开始已保存的动作。不用先去助手里点击“准备连按”；需要配合游戏动作时，自己右键点游戏地面。
  3. 如果 Y＋S 间隔填 200，就是 Y → 等 200 毫秒 → S → 等 200 毫秒再循环。S 模式也可以改间隔，例如填 100 就是每隔 100 毫秒按一次 S。保存新配置会结束当前动作，需回游戏再按 F8；实际节奏受系统与游戏响应影响，卡顿不补发。
  4. 看到游戏下方显示“正在连按 / 按 F8 取消”，就是本次连按的状态提示。
  5. 再按一次 F8 取消，提示会收起。之后想再开，松开按键后重新按 F8 就行。

Esc、Enter、打开 Ctrl+T、按组合键或切出游戏，也会结束本次。Esc／Enter 只结束当前连按，不会阻止你松开按键后下一次单独按 F8 重新开始；切回游戏不会自动继续。右键仍由你自己操作；动作连按和连续开箱不能同时运行。

聊天框开着时，S 或 Y＋S 会输入到聊天框。0.3.11 不再按是否打开聊天框或此前的 Enter／Esc 状态拦截 F8。可以用下方“按 F8 取消”提示判断是否启动，再按 F8 取消；如果要看游戏动作，再由自己关闭输入框并操作。连按按键效果由游戏决定，不保证提高攻击速度。

07B · 自动选爱心天赋（v1.2起）

v1.2 发行包已包含这个功能；v1.0 及更早的包不包含。它不需要翻译 Key，默认关闭。

  1. 先在游戏里给各层想用的天赋标好爱心，选中自己要用的首选方案。
  2. 游戏内“快速选择首选天赋”快捷键保持为 Ctrl＋反引号。反引号在 Esc 下方、数字 1 左边。
  3. 助手打开天赋辅助，勾选“自动选择游戏内的爱心天赋”，再回游戏。开关会保存，下一局自动重新识别；不用每把准备。
  4. 天赋待选时，助手先按下 Ctrl 约 80 毫秒，再按住反引号约 80 毫秒后释放，让游戏先识别修饰键；发送主键前再次核验待选状态与前台。每层只尝试一次，然后回读确认该层是否选中。显示 3 秒未确认时，请检查爱心和快捷键，并手选本层；下一层会继续检测。反复关开开关不会重试本层。

切出游戏时不发按键，也不会抢焦点；后台低频只读，观察返回大厅或换局。使用开箱、连按或快捷输入期间延后。关闭开关后停止读取和发送。看不准自己的玩家身份、游戏版本或天赋状态时暂停。

v1.3 的异常与恢复：本层受阻、未确认或后台错误会在游戏前台短暂被动提示，不抢焦点、鼠标透传；正常成功不弹提示。页面会分开显示已保存的开关偏好与实际运行状态。已勾选却显示“运行已停止 · 开启偏好已保留”时，点重新连接恢复检测；不会重复选择同层天赋，当前层仍按提示手动处理。

实测范围要分开看：build 98348 的霍格、克罗米试用、大厅退出再进、镜像克罗米归属已核对；克罗米一级已实际自动选中，组合键时序修复后，第 2、3 层完成输入对照，第 4 至 7 层通过完整后台服务连续自动补选并回读确认。乱斗自然升级、连续多局和英文客户端还需要实机验证，观战／回放未验收。助手按各英雄真实天赋等级读取，50 毫秒是轮询目标，不保证同一帧选中。游戏中不可选的爱心天赋不会被替换成其他选项；回读只确认“该层已选择”，不独立核对当前爱心目标。

07C · Tab 双击，告诉队友你点的那一项

v1.2 发行包包含双击播报稳定性修复、对局聊天来源与换局探测修复，以及用量账本移除和额度查询入口；保留此前的提速、点击识别、客户端更新和自动首选天赋。先退出旧助手，再启动新文件夹里的 EXE。v1.0 及更早的公开包不包含双击播报。

  1. 在助手打开双击播报，勾选“开启 Tab 双击播报，自动发送到己方团队”。默认关闭，开启后会记住。
  2. 回游戏打开 Tab。双击天赋页里一个已选的天赋，会说明玩家、英雄、真实天赋等级、名称和一句效果。
  3. 双击统计页里一个具体数字，就只说那一项。例如点英雄伤害，只发“【我方】玩家（安度因）｜英雄伤害：12,345”，不会顺带说死亡次数。

击杀、助攻、死亡、英雄伤害、攻城伤害、治疗、自我治疗、经验贡献都按各自一格处理。0 可以说，“—”不说，不给玩家排名或评好坏。自己、队友、对手都能提示，内容发到己方团队。

双击后松开鼠标和按键。v1.3 修复面板读取较慢时正常松开被误取消，以及战斗中可见统计数值变化使整板失效的问题。等待松开时不重复读取整板；过期动作、目标变化和新输入仍会取消，失败不补发。游戏里 Ctrl＋Enter 的团队聊天快捷键保持默认。打开聊天框或菜单、正在开箱／F8 连按／快捷输入时暂停；切出游戏就取消。不改剪贴板、不覆盖你写了一半的话。失败不会自动重试；若留下一段未发送文字，按 Esc 取消。同一项 3 秒内不会重复，任意两次至少间隔 2 秒。

如果没发出来，请看助手“双击播报”页里的状态文字，这里会显示聊天框仍打开、正文未校验完整、操作取消或限频等具体原因，切回助手查看时会保留上次结果。如果文字留在框里，先按 Esc 关闭，再重新双击；若提示“消息可能已经发送”，先查聊天记录，避免重复。状态短暂读不清时会稍等再确认，不会重复输入或补发回车。需要排查时，开启“设置 → 诊断”，复现后导出日志；日志会记录发送阶段、错误码和耗时，不记录播报正文。最下方的大厅／对局文字只是聊天采集来源。Tab 没关就退出对局，也不会把旧目标带到下一局；新局重新打开 Tab 并双击即可。

10 · 有问题，先对照这里

有原文，没有中文翻译

中文消息及纯数字、符号、表情只显示原文，不附翻译状态。需要翻译的英文、韩文消息显示排队中／翻译中时可等待；服务未配置、云翻译关闭、自动翻译暂停或真正不支持的语言会保留原因，失败可看详情再“重试所选”。确认“自动翻译”已勾选、自己的 Key 已配置成功且频道正确。云服务没配好时，助手仍能接收原文。

提示找不到聊天／大厅消息没接上

确认游戏和助手都开着，频道先选“全部聊天”。在游戏里手动发一条普通团队、队伍或密语消息，等它连接，不需要特意再发第二条。0.3.10 已调整首句补收；如果还在用旧版，请先退出旧程序并打开新版。仍不行就到“设置 → 连接 → 手动重新连接”。如果之前停过采集，先点“恢复采集”。独立战网客户端里的聊天不在采集范围；游戏已覆盖或释放的记录也无法补回。

一键连接提示身份验证阶段失败

核对 ID 和 Secret 是否来自同一把 Key，有没有漏字符、多空格、Key 被禁用或删除，以及网络能否访问阿里云。这里填的是 AccessKey，不是阿里云网页登录账号密码。Secret 丢了就创建新 Key，不用反复猜旧 Secret。按窗口的阶段、安全错误类别或可识别云错误码排查；反馈时不用提供 Key。

身份验证通过，翻译测试或保存阶段失败

身份验证成功只说明 Key 能确认身份。翻译测试失败时，检查是否开通“机器翻译通用版”、是否给刚才那个 RAM 用户加了翻译权限，以及阿里云是否有欠费或服务限制。保存阶段可核对当前 Windows 用户和写入权限。看窗口显示的阶段和安全提示排查，等结果后再重试；每次翻译测试均会调用云服务。

旧版本的用量文件需要处理吗？

不用处理。旧 usage.sqlite3 和 usage.sqlite3.initialized 保留原样，当前版本不读取、不新建、不迁移或修复；旧账本缺失或损坏不影响启动、配置或翻译。凭据、语言资料、偏好和日志继续使用原来的 HotsChatHelper 用户目录。

Ctrl+T 翻译了，游戏里却没发出去

它只帮你复制。请回到游戏打开聊天框，Ctrl+V 粘贴，再按 Enter 发送。输入法还在选字时，先确定汉字，再按一次 Enter 提交翻译。快捷键无反应可以从助手主界面的“快捷输入”按钮打开。

按 F8 没出现 s，或者连按没效果

确认使用 v1.3（程序 1.3.0），关闭助手输入条，松开所有修饰键，再回游戏单独按 F8；游戏聊天输入框无需关闭，开着时会输入所选动作的 S 或 Y、S。此前按过 Enter／Esc 也不影响这次启动；运行中按 Enter／Esc 会结束当前连按，松开后可再按 F8 重开。如果改过快捷键，按你保存的那个键。用下方“按 F8 取消”提示判断是否启动；没有提示或有提示但无输入／动作，可分别反馈这两种情况。

游戏里看不到译文，或者位置挡视线

先在主界面确认确实有新的译文。字幕显示时间较短，可在“设置 → 游戏内”调整；用无边框窗口化，重新拖动浮窗位置。透明字幕模式主要显示文字，想要底色可改为半透明面板。

天赋或双击播报已勾选，为什么不运行？

v1.3 分开显示保存的开启偏好与实际运行状态。若页面显示“运行已停止 · 开启偏好已保留”，点该页“重新连接”恢复后台监听；不会重放旧动作。游戏内关键异常提示仅在游戏前台、其他输入功能未占用时显示，成功不弹提示。仍需按失败原因检查游戏快捷键、聊天框或本层天赋。

某个短词翻译不符合语境

主界面保留原文，可以对照着看；需要时选择消息再点“重试所选”。短词缺少上下文时仍可能有多种意思，重试也会调用云翻译，别连续刷同一句。

怎么把日志发给开发者排查？

诊断默认完全关闭。遇到问题时，正式模式打开设置 → 诊断 → 开启诊断日志，复现一次，再点一键导出诊断日志，选择位置保存 ZIP，然后自己发给开发者，并说明出问题的大致时间。开启后的基础日志只记录关键阶段、耗时、错误和编号，不保存聊天正文，也不调用云服务。开关仅本次运行有效，下次启动仍关闭；关闭后已有日志仍可导出。

排查错译或表情时，可先勾选“详细诊断”，复现一次再导出；十分钟后会自动关闭。正文、译文各最多记录 256 字，已配置密钥始终脱敏，分享前仍需检查正文里其他私人信息。不要另外附带 .env、credentials.dpapi 或用户数据库。日志后台有界写入，约 2 MiB × 5 份、保留 7 天；繁忙时允许丢弃诊断并计数。

表情为什么显示为 [表情]？

游戏的图片表情标签会统一显示成 [表情]，避免露出很长的资源路径。只有表情时仅显示原文，不附翻译状态，也不请求云翻译；混合英文、韩文的文字继续正常翻译。普通 Unicode 表情照常显示。

还是解决不了，应该怎么反馈？

说明助手版本、是在大厅还是对局、你做了什么、显示什么提示，以及是否改过快捷键。也可先从“设置 → 诊断”导出日志；截图时遮住 AccessKey、Secret、账号信息、好友昵称和私人聊天。不要把完整 Key 发给别人。

游戏里能看到团队消息、助手却没有原文？本轮已修复对局来源误接大厅记录，以及旧记录持续更新妨碍发现新局的问题；朋友现场是否同因仍需复现确认。请在进局前开启“设置 → 诊断 → 开启诊断日志”，复现后导出 ZIP，并附发生时间。公开 v1.0 不支持这套诊断导出。

大厅队伍昵称偶尔“未知”？0.3.11 已补充同账号的昵称查找：好友关系暂不可读、或者名字只在上层记录里时，会尝试恢复合法昵称。实在无法确认身份或名字数据损坏时仍显示“发送者未知”，正文照常接收。后续新消息会重新查名，旧消息不会自动改名；反馈时说明是否刚组队、同一个人的后续发言有没有恢复，不用提供真实昵称或聊天内容。

11 · 费用和 Key，记住这几句话就够了

实际用量与费用以阿里云控制台为准

想查看剩余额度和实际用量时：

  1. 点击主窗口服务状态行或设置 → 连接 → 翻译服务中的“查询剩余额度”。
  2. 默认浏览器会打开阿里云机器翻译控制台，登录自己的阿里云账号后，在控制台查询。

此按钮仅打开控制台，不自动查询或读取账号数据。助手启动时不会自动打开浏览器，也不会建立本地用量账本。

助手不统计用量或限制月度额度；实际用量与费用以阿里云控制台为准。云端服务的计费方式不因本地功能调整而改变。开通前看清自己账号的实际权益和计费说明，不要把免费权益理解为永久免费。查看官方计费说明

助手不再建立本地月度账本，也不提供月度额度确认或剩余量显示。请求队列、自动翻译限流、缓存去重和暂停继续保留；这些功能不能替代阿里云的账单或账号费用管理。

阿里云控制台测试、助手里的翻译测试、手动重试和实际聊天翻译都会调用云服务。给助手使用专用 Key，并在阿里云控制台查看账号的用量与费用。

Key 放自己手里，别人不需要知道

助手使用 DPAPI 把 Key 加密保存在当前 Windows 用户下；之后可在“个人阿里云密钥”里替换或删除。从助手删除，只删除本机保存的 Key，不会去阿里云注销这把 Key。如果泄露，到 RAM 控制台禁用或删除旧 Key，再创建新的并重新配置助手。

云翻译会把待翻译的消息正文发给阿里云；助手不把发送者昵称当作翻译内容上传。聊天历史只保留本次运行最近 500 条，退出助手后清空。本文不收集 Key，也没有可以填写真实 Key 的网页输入框。

Key 保管与泄露处理参见阿里云 AccessKey 官方说明。

06 · 看别人说什么，发出自己想说的话

A. 看英文、韩文的中文翻译

保持游戏和助手都开着，确认主界面“自动翻译”已勾选，“频道”先选全部聊天。

等游戏里出现一条英文或韩文文字消息。不需要先发一句来“热身”，只发一句也可以等待它接上；新位置的自动定位仍可能需要一些时间。

在主界面的实时消息看原文和译文。游戏里也会短暂显示底部译文；想回看完整内容就切到主界面。

支持你在游戏聊天框里本来就能看到的团队、队伍、密语、所有玩家消息；大厅队伍和密语也可接收。换局、返回大厅时让助手保持打开即可，一般不用每把点重连。中文消息及纯数字、符号、表情只显示原文，不附“不支持”“无需翻译”或“未翻译”状态；真正不支持的语言保留原因，英文与韩文照常翻译。

第一次连上时，会收哪些消息？
大厅队伍、密语：补收这次开启采集以后发出的消息，连接过程中发的第一句也会收。
试用和普通对局：首次找到一条新的聊天记录链时，最多补收该链最近 5 条，可能带上打开助手前的近几条；首次连上前已经连发超过 5 条时，更早的内容可能不在补收范围。之后按新消息继续，不会每次轮询都重翻这 5 条。已有记录位置的重连，也从未读处继续。

| v1.3 消息状态 | 含义和处理

| 中文、纯数字／符号／表情 | 仅显示原文，不附翻译状态，也不调用云翻译。

| 排队中 / 翻译中 | 请求等待处理或正在翻译，可以先等结果。

| 跳过并说明原因 | 需要翻译的消息遇到服务未配置、配置处理中、云翻译已关闭、自动翻译已暂停时保留原因；真正不支持的语言也说明原因。中文及纯数字、符号、表情只显示原文。

| 翻译失败 / 防刷屏已暂缓 | 失败可查看具体提示再“重试所选”；防刷屏不删除原文。手动重试可能调用云服务。

v1.3 给迟到译文留出阅读时间。默认15秒新鲜窗口内获准展示的译文，会获得至少3秒实际阅读时间；新的原文不会立即抢走正在看的译文。较长停留设置会相应延长有界新鲜窗口。过期旧消息不复活，换局或关闭字幕会清理；Ctrl+T 打开时暂藏字幕，收起后只恢复未过期内容，不因隐藏续期。完整历史仍可在主界面查看。

B. 用中文写，让助手帮你译成英语或韩语

Ctrl + T→输入中文、选语言→Enter 翻译→回游戏粘贴发送

07 · F8 动作连按

这个功能可重复按 S，或交替按 Y＋S，不需要翻译 Key。先在助手的“动作连按”页选择动作；S 和 Y＋S 的“按键间隔”都可填 20–5000 毫秒整数，分别保存，新配置均默认 20；旧版保存值保留，然后点击保存并应用。

启动助手正式程序，切回游戏。聊天输入框开着也可以，无需先关闭。

单独按 F8 开始已保存的动作。不用先去助手里点击“准备连按”；需要配合游戏动作时，自己右键点游戏地面。

如果 Y＋S 间隔填 200，就是 Y → 等 200 毫秒 → S → 等 200 毫秒再循环。S 模式也可以改间隔，例如填 100 就是每隔 100 毫秒按一次 S。保存新配置会结束当前动作，需回游戏再按 F8；实际节奏受系统与游戏响应影响，卡顿不补发。

看到游戏下方显示“正在连按 / 按 F8 取消”，就是本次连按的状态提示。

再按一次 F8 取消，提示会收起。之后想再开，松开按键后重新按 F8 就行。

Esc、Enter、打开 Ctrl+T、按组合键或切出游戏，也会结束本次。Esc／Enter 只结束当前连按，不会阻止你松开按键后下一次单独按 F8 重新开始；切回游戏不会自动继续。右键仍由你自己操作；动作连按和连续开箱不能同时运行。

聊天框开着时，S 或 Y＋S 会输入到聊天框。0.3.11 不再按是否打开聊天框或此前的 Enter／Esc 状态拦截 F8。可以用下方“按 F8 取消”提示判断是否启动，再按 F8 取消；如果要看游戏动作，再由自己关闭输入框并操作。连按按键效果由游戏决定，不保证提高攻击速度。

07B · 自动选爱心天赋（v1.2起）

v1.2 发行包已包含这个功能；v1.0 及更早的包不包含。它不需要翻译 Key，默认关闭。

先在游戏里给各层想用的天赋标好爱心，选中自己要用的首选方案。

游戏内“快速选择首选天赋”快捷键保持为 Ctrl＋反引号。反引号在 Esc 下方、数字 1 左边。

助手打开天赋辅助，勾选“自动选择游戏内的爱心天赋”，再回游戏。开关会保存，下一局自动重新识别；不用每把准备。

天赋待选时，助手先按下 Ctrl 约 80 毫秒，再按住反引号约 80 毫秒后释放，让游戏先识别修饰键；发送主键前再次核验待选状态与前台。每层只尝试一次，然后回读确认该层是否选中。显示 3 秒未确认时，请检查爱心和快捷键，并手选本层；下一层会继续检测。反复关开开关不会重试本层。

切出游戏时不发按键，也不会抢焦点；后台低频只读，观察返回大厅或换局。使用开箱、连按或快捷输入期间延后。关闭开关后停止读取和发送。看不准自己的玩家身份、游戏版本或天赋状态时暂停。

v1.3 的异常与恢复：本层受阻、未确认或后台错误会在游戏前台短暂被动提示，不抢焦点、鼠标透传；正常成功不弹提示。页面会分开显示已保存的开关偏好与实际运行状态。已勾选却显示“运行已停止 · 开启偏好已保留”时，点重新连接恢复检测；不会重复选择同层天赋，当前层仍按提示手动处理。

实测范围要分开看：build 98348 的霍格、克罗米试用、大厅退出再进、镜像克罗米归属已核对；克罗米一级已实际自动选中，组合键时序修复后，第 2、3 层完成输入对照，第 4 至 7 层通过完整后台服务连续自动补选并回读确认。乱斗自然升级、连续多局和英文客户端还需要实机验证，观战／回放未验收。助手按各英雄真实天赋等级读取，50 毫秒是轮询目标，不保证同一帧选中。游戏中不可选的爱心天赋不会被替换成其他选项；回读只确认“该层已选择”，不独立核对当前爱心目标。

10 · 有问题，先对照这里

有原文，没有中文翻译
中文消息及纯数字、符号、表情只显示原文，不附翻译状态。需要翻译的英文、韩文消息显示排队中／翻译中时可等待；服务未配置、云翻译关闭、自动翻译暂停或真正不支持的语言会保留原因，失败可看详情再“重试所选”。确认“自动翻译”已勾选、自己的 Key 已配置成功且频道正确。云服务没配好时，助手仍能接收原文。

提示找不到聊天／大厅消息没接上
确认游戏和助手都开着，频道先选“全部聊天”。在游戏里手动发一条普通团队、队伍或密语消息，等它连接，不需要特意再发第二条。0.3.10 已调整首句补收；如果还在用旧版，请先退出旧程序并打开新版。仍不行就到“设置 → 连接 → 手动重新连接”。如果之前停过采集，先点“恢复采集”。独立战网客户端里的聊天不在采集范围；游戏已覆盖或释放的记录也无法补回。

一键连接提示身份验证阶段失败
核对 ID 和 Secret 是否来自同一把 Key，有没有漏字符、多空格、Key 被禁用或删除，以及网络能否访问阿里云。这里填的是 AccessKey，不是阿里云网页登录账号密码。Secret 丢了就创建新 Key，不用反复猜旧 Secret。按窗口的阶段、安全错误类别或可识别云错误码排查；反馈时不用提供 Key。

身份验证通过，翻译测试或保存阶段失败
身份验证成功只说明 Key 能确认身份。翻译测试失败时，检查是否开通“机器翻译通用版”、是否给刚才那个 RAM 用户加了翻译权限，以及阿里云是否有欠费或服务限制。保存阶段可核对当前 Windows 用户和写入权限。看窗口显示的阶段和安全提示排查，等结果后再重试；每次翻译测试均会调用云服务。

旧版本的用量文件需要处理吗？
不用处理。旧 usage.sqlite3 和 usage.sqlite3.initialized 保留原样，当前版本不读取、不新建、不迁移或修复；旧账本缺失或损坏不影响启动、配置或翻译。凭据、语言资料、偏好和日志继续使用原来的 HotsChatHelper 用户目录。

Ctrl+T 翻译了，游戏里却没发出去
它只帮你复制。请回到游戏打开聊天框，Ctrl+V 粘贴，再按 Enter 发送。输入法还在选字时，先确定汉字，再按一次 Enter 提交翻译。快捷键无反应可以从助手主界面的“快捷输入”按钮打开。

按 F8 没出现 s，或者连按没效果
确认使用 v1.3（程序 1.3.0），关闭助手输入条，松开所有修饰键，再回游戏单独按 F8；游戏聊天输入框无需关闭，开着时会输入所选动作的 S 或 Y、S。此前按过 Enter／Esc 也不影响这次启动；运行中按 Enter／Esc 会结束当前连按，松开后可再按 F8 重开。如果改过快捷键，按你保存的那个键。用下方“按 F8 取消”提示判断是否启动；没有提示或有提示但无输入／动作，可分别反馈这两种情况。

游戏里看不到译文，或者位置挡视线
先在主界面确认确实有新的译文。字幕显示时间较短，可在“设置 → 游戏内”调整；用无边框窗口化，重新拖动浮窗位置。透明字幕模式主要显示文字，想要底色可改为半透明面板。

天赋或双击播报已勾选，为什么不运行？
v1.3 分开显示保存的开启偏好与实际运行状态。若页面显示“运行已停止 · 开启偏好已保留”，点该页“重新连接”恢复后台监听；不会重放旧动作。游戏内关键异常提示仅在游戏前台、其他输入功能未占用时显示，成功不弹提示。仍需按失败原因检查游戏快捷键、聊天框或本层天赋。

某个短词翻译不符合语境
主界面保留原文，可以对照着看；需要时选择消息再点“重试所选”。短词缺少上下文时仍可能有多种意思，重试也会调用云翻译，别连续刷同一句。

怎么把日志发给开发者排查？
诊断默认完全关闭。遇到问题时，正式模式打开设置 → 诊断 → 开启诊断日志，复现一次，再点一键导出诊断日志，选择位置保存 ZIP，然后自己发给开发者，并说明出问题的大致时间。开启后的基础日志只记录关键阶段、耗时、错误和编号，不保存聊天正文，也不调用云服务。开关仅本次运行有效，下次启动仍关闭；关闭后已有日志仍可导出。

排查错译或表情时，可先勾选“详细诊断”，复现一次再导出；十分钟后会自动关闭。正文、译文各最多记录 256 字，已配置密钥始终脱敏，分享前仍需检查正文里其他私人信息。不要另外附带 .env、credentials.dpapi 或用户数据库。日志后台有界写入，约 2 MiB × 5 份、保留 7 天；繁忙时允许丢弃诊断并计数。

表情为什么显示为 [表情]？
游戏的图片表情标签会统一显示成 [表情]，避免露出很长的资源路径。只有表情时仅显示原文，不附翻译状态，也不请求云翻译；混合英文、韩文的文字继续正常翻译。普通 Unicode 表情照常显示。

还是解决不了，应该怎么反馈？
说明助手版本、是在大厅还是对局、你做了什么、显示什么提示，以及是否改过快捷键。也可先从“设置 → 诊断”导出日志；截图时遮住 AccessKey、Secret、账号信息、好友昵称和私人聊天。不要把完整 Key 发给别人。

游戏里能看到团队消息、助手却没有原文？本轮已修复对局来源误接大厅记录，以及旧记录持续更新妨碍发现新局的问题；朋友现场是否同因仍需复现确认。请在进局前开启“设置 → 诊断 → 开启诊断日志”，复现后导出 ZIP，并附发生时间。公开 v1.0 不支持这套诊断导出。

大厅队伍昵称偶尔“未知”？0.3.11 已补充同账号的昵称查找：好友关系暂不可读、或者名字只在上层记录里时，会尝试恢复合法昵称。实在无法确认身份或名字数据损坏时仍显示“发送者未知”，正文照常接收。后续新消息会重新查名，旧消息不会自动改名；反馈时说明是否刚组队、同一个人的后续发言有没有恢复，不用提供真实昵称或聊天内容。

实际用量与费用以阿里云控制台为准

想查看剩余额度和实际用量时：

点击主窗口服务状态行或设置 → 连接 → 翻译服务中的“查询剩余额度”。

默认浏览器会打开阿里云机器翻译控制台（https://mt.console.aliyun.com/service），登录自己的阿里云账号后，在控制台查询。

此按钮仅打开控制台，不自动查询或读取账号数据。助手启动时不会自动打开浏览器，也不会建立本地用量账本。

助手不统计用量或限制月度额度；实际用量与费用以阿里云控制台为准。云端服务的计费方式不因本地功能调整而改变。开通前看清自己账号的实际权益和计费说明，不要把免费权益理解为永久免费。查看官方计费说明（https://help.aliyun.com/zh/machine-translation/product-overview/billing-overview）

助手不再建立本地月度账本，也不提供月度额度确认或剩余量显示。请求队列、自动翻译限流、缓存去重和暂停继续保留；这些功能不能替代阿里云的账单或账号费用管理。

阿里云控制台测试、助手里的翻译测试、手动重试和实际聊天翻译都会调用云服务。给助手使用专用 Key，并在阿里云控制台查看账号的用量与费用。

Key 放自己手里，别人不需要知道

助手使用 DPAPI 把 Key 加密保存在当前 Windows 用户下；之后可在“个人阿里云密钥”里替换或删除。从助手删除，只删除本机保存的 Key，不会去阿里云注销这把 Key。如果泄露，到 RAM 控制台禁用或删除旧 Key，再创建新的并重新配置助手。

云翻译会把待翻译的消息正文发给阿里云；助手不把发送者昵称当作翻译内容上传。聊天历史只保留本次运行最近 500 条，退出助手后清空。本文不收集 Key，也没有可以填写真实 Key 的网页输入框。

Key 保管与泄露处理参见阿里云 AccessKey 官方说明（https://help.aliyun.com/zh/ram/user-guide/create-an-accesskey-pair）。

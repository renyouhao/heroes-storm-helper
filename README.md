# 风暴英雄助手

Windows 上的《风暴英雄》聊天翻译与游戏内辅助工具。

本仓库用于**完整安装包分发、更新检查和用户反馈**，不包含业务源码或源码历史。下载页中的 `Source code` 自动归档只有本仓库的说明和发行元数据，不能用来运行助手。

## 下载与更新

- [下载最新完整 Windows x64 包](https://github.com/renyouhao/heroes-storm-helper/releases/latest)
- [v3.0 完整包](https://github.com/renyouhao/heroes-storm-helper/releases/download/v3.0/HotsHelper-3.0.0-Windows-x64.zip)
- [SHA256 校验文件](https://github.com/renyouhao/heroes-storm-helper/releases/download/v3.0/HotsHelper-3.0.0-Windows-x64.zip.sha256)

退出旧助手，完整解压 ZIP，保留整个目录和 `_internal`，再运行新目录中的“风暴英雄助手.exe”。发给朋友时发送完整 ZIP。

现有助手的检查更新地址保持不变，无需配置 GitHub 账号或访问私有源码仓库。官网或独立下载网页也可以链接上述安装包。

v3.0（3.0.0），Windows x64。当前朋友内测继续免费；云翻译仍使用用户自己的服务商账户，费用由服务商按账户实际用量结算。

本次只调整源码与成品的仓库分工，分发包与原 v3.0 相同，没有新增会员、试用到期或收费限制。程序内的完整使用说明与已知验收边界随包提供。

## 反馈问题和提出需求

[提交问题或新需求](https://github.com/renyouhao/heroes-storm-helper/issues/new)

登录 GitHub 后即可提出 Issue，无需申请源码仓库协作权限。请说明版本、复现步骤、预期结果和实际结果。需要诊断时，在助手中开启录制，复现后导出诊断 ZIP；公开上传前检查聊天内容等个人信息，不上传 API Key 或其他凭据。

源码仓库调整前的历史反馈保留在维护者的私有记录中。如需继续讨论旧问题，请在这里新建 Issue，并注明原编号和问题摘要。

# 风暴英雄助手

本仓库提供风暴英雄助手的 Windows 安装包、更新说明，以及问题反馈和需求收集入口。程序源码保存在私有仓库。

## 下载和更新

请在 [GitHub Releases](https://github.com/renyouhao/heroes-storm-helper/releases) 打开对应版本，下载资产中的 Windows x64 ZIP。每个发行附有更新说明和 SHA-256 校验文件。已支持检查更新的版本也可在助手内确认下载。

## 反馈问题和提出需求

[提交问题或新需求](https://github.com/renyouhao/heroes-storm-helper/issues/new)

登录 GitHub 后即可提出 Issue，无需申请源码仓库协作权限。请说明版本、复现步骤、预期结果和实际结果。需要诊断时，在助手中开启录制，复现后导出诊断 ZIP；公开上传前检查聊天内容等个人信息，不上传 API Key 或其他凭据。

源码仓库调整前的历史反馈保留在维护者的私有记录中。如需继续讨论旧问题，请在这里新建 Issue，并注明原编号和问题摘要。

## 仓库范围

当前分发状态见 [distribution.json](distribution.json)。GitHub 随标签生成的源码归档只包含这个公开仓库的说明与元数据。

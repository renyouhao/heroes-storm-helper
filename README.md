# 风暴英雄助手 · Heroes of the Storm Helper

**简体中文** | [English](README.en.md)

Windows 上的《风暴英雄》聊天翻译与游戏内辅助工具。把收到的英文、韩文聊天翻译成中文，也能把你输入的中文翻译成英文或韩文，由你粘贴发送。

**v1.3 发行版本，程序内版本1.3.0**。下方提供对应 Windows 完整包与发行说明入口。旧密钥、语言资料和偏好继续保留。适配 Windows x64、中文客户端 **build 98348**；英文项目介绍不代表英文游戏客户端已经验收。

## v1.3 界面与体验更新

- **更清楚的操作界面**：沿用 Notion 风格的中性配色与紧凑侧栏，按钮、输入框和卡片参考 Codex 调整圆角；选中配置显示真正的 **✓**。Ctrl+T 保留深色高对比、Enter 翻译并复制、Esc 收起与 Ctrl+Tab 切换语言。本版使用独立助手图标：六角风暴徽记，右下聊天气泡。
- **翻译状态可区分**：实时消息显示“排队中”“翻译中”“翻译失败”，跳过时说明未配置、云翻译关闭、自动翻译暂停、语言不支持或内容无需翻译等原因；失败详情与“重试所选”保留。
- **字幕留出阅读时间**：默认在15秒新鲜窗口内获准展示的迟到译文会获得至少3秒实际阅读时间，新原文不会立即抢走当前译文。较长停留设置会相应延长有界新鲜窗口；过期旧内容不复活，换局、关闭字幕会清理，打开 Ctrl+T 暂藏字幕时不延长原期限。
- **异常与恢复更明确**：天赋待选受阻、未确认或后台错误，以及双击播报错误，在游戏前台显示短暂被动提示，鼠标透传、不抢焦点；成功不弹提示。各辅助页分别显示已保存的开启偏好与实际运行状态，后台意外停止后可点“重新连接”恢复监听，不重放旧操作。
- **降低重复绘制**：聊天跟随最新时增量更新变化行；圆角使用固定共享图片与单个卡片图元，换肤/DPI变化原地复用，无动画或额外轮询。

此前对500条合成聊天的离线比较中，新增消息与译文刷新中位耗时约降低 **65%**；这属于上一轮同条件测量，并非游戏实战帧率结论。此前离线整窗约 **60 MiB 私有内存、90 MiB 工作集**，不包含真实游戏或云负载，也不代表所有电脑及冻结包的占用。实际对局 CPU、内存与输入表现仍待验收。

## 功能

- **实时翻译**：支持团队、队伍、密语及所有玩家频道；大厅和对局分别采集，换局后自动接续。
- **快捷输入**：按 `Ctrl+T` 输入中文、选择英语或韩语，翻译后复制，由你回游戏粘贴发送。
- **自己的 Key 一键连接**：填写阿里云 AccessKey ID / Secret，点击“连接并开始使用”，自动验证、测试翻译、加密保存并启用。
- **游戏内字幕**：默认底部透明字幕，可调整位置、字号、停留时间和背景。
- **三套配色**：月白蓝、石墨紫、雾青；v1.3 桌面采用中性色调，游戏内输入与字幕继续保持深色高对比。
- **常用短句**：管理自己的常用表达。
- **开箱助手**：在助手中点击“准备开箱”，手动切到游戏补给箱页，按空格开始、暂停或继续；按 Esc 结束。
- **动作连按**：在“动作连按”页选择 S 或 Y+S，填写“按键间隔”后“保存并应用”，游戏前台按 `F8` 启停。两种动作分别保存间隔，都可设 20–5000 毫秒，新配置默认 20；已有自定义值会保留。Esc、Enter 或切出游戏会结束；聊天框开着时按键会输入其中。
- **自动首选天赋**：在“天赋辅助”开启，出现待选层时触发一次游戏内的 `Ctrl+反引号`，再回读确认。复用已标爱心的方案，默认关闭，不需要翻译 Key；开箱、连按或快捷输入期间延后。
- **Tab 双击播报**：单独开启后，在游戏 Tab 天赋页双击一个已选天赋，向己方团队说明玩家、英雄、真实天赋等级、名称及一句效果；统计页双击哪一项，就只播报该项的数值。默认关闭，不需要翻译 Key。
- **客户端更新**：主窗点击“检查更新”，手动检查、下载校验，再点击“重启并更新”。只使用官方仓库的稳定发行包，不在启动时联网检查。v1.3 与包内 1.3.0 表示同一版本，同版本不会重复升级；更新器支持 `HotsHelper-<版本>-Windows-x64.zip` 附件名。v1.0 没有内置更新按钮，1.1.0 本地包的旧更新器只识别中文名，这两种旧包均请从上方手动下载完整包。
- **图片表情**：游戏正文中的完整图片表情标签显示为 `[表情]`，纯表情不调用云翻译，英文、韩文混合消息继续翻译。
- **轻量诊断**：默认完全关闭，不启动写入线程、不创建日志文件。有问题时到“设置 → 诊断”开启，复现后“一键导出诊断日志”；开关仅本次运行有效。开启后只保存关键阶段、错误和编号，也可单独开启十分钟详细正文，完整密钥保持脱敏。

## 普通用户怎么用

从上方 Release 下载完整的 Windows 发行包，解压后双击“风暴英雄助手.exe”。保留整个目录及 `_internal` 文件夹，无需另装 Python 或 SDK。EXE 和安装包作为 Release 附件提供，私人配置不随包分发。

1. 在自己的阿里云账号下开通**机器翻译通用版**，为助手创建 RAM 用户及 AccessKey，授予 `alimt:TranslateGeneral` 权限。
2. 在助手中填写自己的 AccessKey ID、AccessKey Secret。
3. 点击一次**“连接并开始使用”**。助手先验证账号身份，再测试翻译“你好”，成功后使用 DPAPI 加密保存密钥并启用翻译。
4. 启动游戏，频道先选“全部聊天”，收到英文或韩文消息后查看译文。建议使用无边框窗口化。

完整申请步骤、使用方式和问题排查见[新手指南（HTML，下载后可离线打开）](artifacts/风暴英雄助手新手指南.html)。

云翻译需要联网，调用费用按你自己的阿里云账号计费。助手不统计用量或限制月度额度；实际用量与费用以阿里云控制台为准。配置时不再填写“本月其他用量”或确认额度，界面不显示月度剩余量，也没有本地 90 万字符上限。请求队列、自动翻译限流、缓存去重和暂停功能继续保留。也可跳过云配置，先使用原文展示、开箱及连按功能。

想查看剩余额度和实际用量时，点击主窗口服务状态行或“设置 → 连接 → 翻译服务”中的**“查询剩余额度”**，助手会用默认浏览器打开[阿里云机器翻译控制台](https://mt.console.aliyun.com/service)。登录自己的阿里云账号后，在控制台查询。助手仅提供跳转入口，不自动查询或读取账号数据，启动时也不会自动打开浏览器。

## Tab 双击播报与更新

在助手的“**双击播报**”页勾选开关，再回游戏打开 Tab。双击天赋页中一个**已选择**的天赋，助手会向**己方团队**发送，例如：`【敌方】玩家（克罗米）｜5级天赋「莫比乌斯回路」：……`。层级读取英雄的真实目录，克罗米等特殊英雄不会套用常规等级。中文短效果随包离线提供，不现场调用 AI，也不增加翻译用量。

统计页**点哪一项，只发哪一项**。支持击杀、助攻、死亡、英雄伤害、攻城伤害、治疗、自我治疗和经验贡献；例如只双击英雄伤害：`【我方】玩家（安度因）｜英雄伤害：12,345`，不会带上死亡或其他数据，不加个人排名、表现评价。数值使用发送准备时最后一次可信读取的快照，持续变化不会把同一格当成别的目标。显示 `0` 可以播报，显示 `—` 不播报。玩家与格子归属、面板可见性或数据无法确认时不发送。

开关默认关闭，偏好可保存；演示模式不监听双击。双击后松开鼠标和按键，保持游戏前台。游戏的 **Ctrl＋Enter 团队聊天快捷键**须保持默认；聊天框、菜单、开箱、F8 连按、快捷输入或升级准备期间暂停。发送前核对团队空框，输入后逐字回读，再提交；不改剪贴板，不覆盖用户草稿。失败不自动重试，可能留下未提交文字，可按 Esc 取消。同一项 3 秒内不重复尝试，任意两项间隔至少 2 秒，关开开关不能绕过限频。

兼容带 Windows 注入标记的桌面点击，助手自身标记的输入仍被忽略。未识别到格子、操作取消和限频原因会显示在助手的“双击播报”页。主窗口底部的大厅／对局文字表示聊天采集来源，不代表双击播报的开关或当前识别结果。即使 Tab 没关就退出对局，旧对局的待发动作也会失效；新局需要重新打开面板并双击，不沿用上一局目标。

本轮将动作连按的会话状态与发送互斥分开：空闲监听不再因播报持有输出锁而阻塞键盘或计时回调；F8、Esc 仍及时处理，连按输出等待当前发送结束，取消仍等待已有输入结束。正文沿用批量 Unicode 输入，不改剪贴板；并非逐字设置延时。

输入框状态短暂变化时，只在已确认的同一对局内做有界只读重采样，每个确认阶段以 400 毫秒为期限；稳定时立即继续。正文与提交按键不会因重采样重复执行。换局、菜单打开、切出或新的按键／鼠标操作仍会停止本次发送。若文字留在框里，先看“双击播报”页的具体原因；聊天框仍打开时，先按 Esc 关闭，再双击。若提示“消息可能已经发送”，请先查聊天记录，避免重复。切回助手查看时，普通点击不会覆盖上次结果。需要排查时可开启“设置 → 诊断”，复现后导出；会记录失败阶段、错误码、耗时和字数，不写播报正文。

此功能只在点击或已有待发动作时读取面板，右键移动与空闲不触发整板读取；鼠标事件保持透传。当前针对中文 build 98348 做试用只读对照；用户已在前一修复包确认天赋与统计双击能发到团队；本轮提速后的完整实机耗时、乱斗连续多局、英文客户端、其他分辨率仍需要验收。未知版本不发送。

v1.3 中，关键异常也会在游戏前台短暂提示；普通成功保持安静。若已勾选开关但页面显示“运行已停止 · 开启偏好已保留”，可点“重新连接”恢复后台监听。它不会重发失败消息或重复选择同层天赋；播报失败后仍需按原因处理，再由你重新双击。

更新时点击主窗“**检查更新**”，确认新版本说明后点“下载更新”，完成后点“重启并更新”。只读取 `renyouhao/heroes-storm-helper` 官方稳定 Release；不降级，也不在启动时自动联网。缺少可信 SHA256 或完整发行包时不给自动安装入口。完整包校验后，独立升级程序等待旧助手退出，备份并替换程序目录，再启动新版本；失败尝试恢复旧程序，保留本机密钥、语言资料与偏好。请放在可写的普通目录，保留整个程序文件夹。

从源码运行时可以检查和下载，界面显示可复制的 ZIP 路径；源码目录不会被替换。关闭助手或重新检查会回收未交给升级程序的暂存包。更新核心已用临时目录测试替换、回滚和异常分支；真实冻结版跨版本替换仍待验收，新版启动检查仅确认短期存活。

## 本机数据与隐私

用户数据由助手自动创建在 `%LOCALAPPDATA%\HotsChatHelper`，不需要手动建文件或从别人电脑复制。

- 密钥保存为当前 Windows 用户绑定的 DPAPI 加密文件，不能当作可共享配置分发。
- 凭据、语言资料（含常用短句）、偏好与诊断日志继续使用上述用户目录；密钥、用户数据库和真实聊天采样不提交到本仓库。
- 旧版本的 `usage.sqlite3` 与 `usage.sqlite3.initialized` 保留原样，当前版本不读取、不新建，也不迁移或修复；旧账本缺失或损坏不影响启动、云配置或翻译。助手不再建立本地月度账本。
- 正式启动不自动读取项目 `.env`，不使用共享密钥；只有主动选择“导入本机旧 .env”时才读取所选文件。
- 云翻译会将待翻译正文发送给阿里云，发送者昵称不作为翻译正文上传。
- 界面聊天历史保留本次运行最近 500 条，退出后清空。诊断默认关闭，需用户主动开启；基础模式不含正文，详细模式下正文和译文各最多记录 256 字，十分钟后自动结束详细模式。
- 日志在本机 `logs` 子目录后台限量保存，约 2 MiB × 5 份、保留 7 天；过载允许丢弃诊断并计数，不等待磁盘。导出仅含日志与安全摘要，不自动上传，也不包含凭据文件、数据库或偏好。
- 已配置的 Key/Secret 会脱敏，详细正文中其他私人信息仍需用户在分享前检查。导出不需要云调用，也不触发付费测试。

## 从源码运行

需要 Windows x64、Python **3.10 或以上**（发行包使用 Python 3.12 构建）。在项目根目录用 PowerShell 执行：

```powershell
.\安装依赖.ps1
.\启动助手.ps1 -Demo  # 离线演示，不读取游戏、真实凭据或调用云服务
.\启动助手.ps1        # 正式运行，使用自己的 Key
```

也可手动建立虚拟环境：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install --no-deps -e .
.\.venv\Scripts\python.exe -m hots_chat.app --demo
```

Python 发行包名为 `hots-assistant`；源码模块和本机数据目录沿用 `hots_chat`、`HotsChatHelper`。

## 测试

以下测试使用合成数据、受控离线云服务和临时用户目录。Windows 下的界面集成测试会创建自有隐藏 Tk 窗口，不操作用户正在使用的游戏或助手界面。

对局采集现在只用团队／所有玩家消息校准对局来源，避免误接大厅／密语记录。旧聊天仍持续更新时也会按有界计划探测其他来源，避免一直停留在旧局；大厅队伍与密语继续由独立来源接收。朋友现场的漏采是否属于同一原因仍需复现确认，v1.0 没有诊断导出；本轮版本可在进局前开启“设置 → 诊断”，复现后导出 ZIP 并附发生时间。

## 常见问题

**账号已验证，翻译仍失败**：身份验证只说明 Key 能识别账号，还需开通机器翻译通用版、授予翻译权限并保证账号服务可用。0.3.12 会显示失败阶段及安全错误类别；检查提示后再重试。

**没有中文译文**：先看消息旁的状态。排队中或翻译中可等结果；v1.3 会说明未配置、云翻译关闭、自动翻译暂停或语言不支持等跳过原因，失败可查看详情再“重试所选”。确认自己的 Key 已连接、自动翻译已开启且频道筛选正确；当前接收翻译只支持英文和韩文。

**返回大厅或换局后没消息**：先在游戏内发送一条普通聊天；仍不恢复可在“设置 → 连接”手动重新连接。独立战网客户端的聊天不在采集范围内。

**大厅昵称显示未知**：助手会尝试从已验证的同账号记录恢复昵称；无法确认身份时保留未知，不猜测其他玩家的名字。旧未知消息不自动补名。

**辅助功能已勾选却停止了**：v1.3 会把保存的开启偏好与实际运行状态分开显示。天赋辅助或双击播报显示“运行已停止”时，可点该页“重新连接”；确认游戏前台及输入空闲后再操作，不会自动补发旧动作。

**F8 没有效果**：确认游戏在前台、单独按 F8 并松开组合键；查看底部状态提示。可在“设置 → 快捷键”修改为 F1–F12。

**连按间隔怎么设置**：在“动作连按”选择 S 或 Y+S，填写“按键间隔”后点“保存并应用”，再回游戏按 F8。两种动作都能编辑，范围 20–5000 毫秒，分别保存，新配置均默认 20；旧版本保存过的 Y+S 间隔继续使用。S 填 100 表示每隔 100 毫秒按一次 S；Y+S 填 200 表示 Y → 等 200 毫秒 → S → 等 200 毫秒再循环。保存配置会结束当前动作，不会立即自动开始；实际节奏受 Windows 和游戏响应影响，卡顿不补发。

**如何反馈链路问题**：先到“设置 → 诊断”勾选“开启诊断日志”，复现问题后导出 ZIP，说明大致时间与操作。错译或表情问题可另勾详细诊断；它会记录限长聊天内容，分享前自行检查。关闭后不再记录新事件，已有日志仍可导出；下次启动仍默认关闭。完整密钥不进入日志，不要另行附带 `.env` 或 `credentials.dpapi`。

**自动首选天赋怎么用**：先在游戏里给想用的每层天赋标好爱心，保持“快速选择首选天赋”快捷键为 `Ctrl+反引号`（Esc 下方、数字 1 左边的键），在助手“天赋辅助”勾选开关后回游戏。偏好会保存，换局重新识别本地玩家；关闭后停止读取和发送。只向当前前台的目标游戏发送按键，不抢焦点，后台低频只读以观察换局。组合键分阶段发送：Ctrl 先按下约 80 毫秒，再按住反引号约 80 毫秒，最后释放；主键发送前再次核验本层和游戏前台，避免游戏尚未识别 Ctrl 就收到主键。每层只尝试一次并回读确认，3 秒未确认就提示手动处理；补爱心或改快捷键后，请手选本层，下一层继续检测。人工先选、短暂读取失败或关开功能不会触发同层重复发送。

**乱斗、其他英雄和英文支持到哪一步**：读取当前英雄目录中的真实解锁等级，克罗米使用 `1/2/5/8/11/14/18`；不靠中文名称、屏幕坐标或固定玩家槽。已在 build 98348 试用完成霍格多层手选对照、克罗米特殊层级对照、大厅退出再进、敌我镜像克罗米与友军归属读取；克罗米第 1 层曾实测自动选中，本次时序修复后第 2、3 层完成输入对照，第 4 至 7 层通过完整后台服务连续自动补选并逐层回读确认。普通对局和乱斗的自然升级、连续多局及英文客户端尚待实机验收。禁用层和附加条件参与读取判断，最终首选由游戏处理，助手不替换不可选的爱心天赋。未知 build、身份或模式不发送；观战/回放未验收。50 毫秒是目标轮询间隔，实际选中时间受系统和游戏影响，不保证同一帧。回读确认表示该层已选择，助手没有独立读取当前爱心方案来核对特定目标。

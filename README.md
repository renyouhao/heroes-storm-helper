# 风暴英雄助手

本仓库用于《风暴英雄》助手的问题反馈、需求收集和使用讨论。

**本仓库不保留 Release、EXE、完整安装包或自动更新包。** 本仓库不包含业务源码或源码历史。

## 内测包与更新

内测用户请通过原有渠道获取完整包和使用说明。发行包保存在私有仓库；公开下载及安装包更新现已暂停。

本次仅调整公开分发状态，不会改变已经安装的程序或增加收费限制。

## 反馈问题和提出需求

[提交问题或新需求](https://github.com/renyouhao/heroes-storm-helper/issues/new)

登录 GitHub 后即可提出 Issue，无需申请源码仓库协作权限。请说明版本、复现步骤、预期结果和实际结果。需要诊断时，在助手中开启录制，复现后导出诊断 ZIP；公开上传前检查聊天内容等个人信息，不上传 API Key 或其他凭据。

源码仓库调整前的历史反馈保留在维护者的私有记录中。如需继续讨论旧问题，请在这里新建 Issue，并注明原编号和问题摘要。

## 仓库范围

当前分发状态见 [distribution.json](distribution.json)。历史标签和自动生成的 `Source code` 归档只包含公开说明与元数据，不是助手安装包。

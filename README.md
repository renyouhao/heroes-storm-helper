# 风暴英雄助手

Windows 上的《风暴英雄》聊天翻译助手。接收游戏内聊天，将英文、韩文翻译为中文，也可以把你输入的中文翻译成英文或韩文，再由你粘贴发送。

当前源码与本地候选包版本：**1.1.0**（对应两段发布编号 **1.1**）；下方公开下载仍为已发布的 **v1.0**（原构建号 0.3.12）。本地 1.1.0 包累计包含轻量诊断、图片表情处理、S/Y+S 分别配置间隔以及自动首选天赋，尚未发布到 GitHub。Windows x64、中文游戏客户端 **build 98348** 已做本机对照；游戏更新后需重新验证读取。

本地包为 `releases/风暴英雄助手-1.1.0-Windows-x64.zip`。旧的公开包和本地 0.3.14 ZIP 不含自动首选天赋。

## 功能

- **实时翻译**：支持团队、队伍、密语及所有玩家频道；大厅和对局分别采集，换局后自动接续。
- **快捷输入**：按 `Ctrl+T` 输入中文、选择英语或韩语，翻译后复制，由你回游戏粘贴发送。
- **自己的 Key 一键连接**：填写阿里云 AccessKey ID / Secret，点击“连接并开始使用”，自动验证、测试翻译、加密保存并启用。
- **游戏内字幕**：默认底部透明字幕，可调整位置、字号、停留时间和背景。
- **三套配色**：月白蓝、石墨紫、雾青，主界面、设置和浮窗统一。
- **常用短句**：管理自己的常用表达。
- **开箱助手**：在助手中点击“准备开箱”，手动切到游戏补给箱页，按空格开始、暂停或继续；按 Esc 结束。
- **动作连按**：在“动作连按”页选择 S 或 Y+S，填写“按键间隔”后“保存并应用”，游戏前台按 `F8` 启停。两种动作分别保存间隔，都可设 20–5000 毫秒，新配置默认 20；已有自定义值会保留。Esc、Enter 或切出游戏会结束；聊天框开着时按键会输入其中。
- **自动首选天赋（本地 1.1.0）**：在“天赋辅助”开启，出现待选层时触发一次游戏内的 `Ctrl+反引号`，再回读确认。复用已标爱心的方案，默认关闭，不需要翻译 Key；开箱、连按或快捷输入期间延后。
- **图片表情**：游戏正文中的完整图片表情标签显示为 `[表情]`，纯表情不调用云翻译，英文、韩文混合消息继续翻译。
- **轻量诊断**：默认完全关闭，不启动写入线程、不创建日志文件。有问题时到“设置 → 诊断”开启，复现后“一键导出诊断日志”；开关仅本次运行有效。开启后只保存关键阶段、错误和编号，也可单独开启十分钟详细正文，完整密钥保持脱敏。

## 普通用户怎么用

从上方 Release 下载完整的 Windows 发行包，解压后双击“风暴英雄助手.exe”。保留整个目录及 `_internal` 文件夹，无需另装 Python 或 SDK。EXE 和安装包作为 Release 附件提供，私人配置不随包分发。

1. 在自己的阿里云账号下开通**机器翻译通用版**，为助手创建 RAM 用户及 AccessKey，授予 `alimt:TranslateGeneral` 权限。
2. 在助手中填写自己的 AccessKey ID、AccessKey Secret。
3. “本月其他用量”首次默认 **0**，可修改；它是你填写的数值，不是自动查询的云端用量。已有同账号的非零记录会保留，同月不能调低。
4. 点击一次**“连接并开始使用”**。助手测试翻译“你好”，预留 2 字符，成功后加密保存并启用翻译。
5. 启动游戏，频道先选“全部聊天”，收到英文或韩文消息后查看译文。建议使用无边框窗口化。

完整申请步骤、使用方式和问题排查见[新手指南（HTML，下载后可离线打开）](artifacts/风暴英雄助手新手指南.html)。

云翻译需要联网，调用费用按你自己的阿里云账号计费。也可跳过云配置，先使用原文展示、开箱及连按功能。

## 本机数据与隐私

用户数据由助手自动创建在 `%LOCALAPPDATA%\HotsChatHelper`，不需要手动建文件或从别人电脑复制。

- 密钥保存为当前 Windows 用户绑定的 DPAPI 加密文件，不能当作可共享配置分发。
- 用量账本、短句和偏好保存在本机；密钥、用户数据库和真实聊天采样不提交到本仓库。
- 正式启动不自动读取项目 `.env`，不使用共享密钥；只有主动选择“导入本机旧 .env”时才读取所选文件。
- 云翻译会将待翻译正文发送给阿里云，发送者昵称不作为翻译正文上传。
- 界面聊天历史保留本次运行最近 500 条，退出后清空。诊断默认关闭，需用户主动开启；基础模式不含正文，详细模式下正文和译文各最多记录 256 字，十分钟后自动结束详细模式。
- 日志在本机 `logs` 子目录后台限量保存，约 2 MiB × 5 份、保留 7 天；过载允许丢弃诊断并计数，不等待磁盘。导出仅含日志与安全摘要，不自动上传，也不包含凭据文件、数据库或偏好。
- 已配置的 Key/Secret 会脱敏，详细正文中其他私人信息仍需用户在分享前检查。导出不需要云调用，也不触发付费测试。

## 从源码运行

需要 Windows x64、Python **3.10 或以上**（发行包使用 Python 3.12 构建）。在项目根目录用 PowerShell 执行：

```powershell
.\安装依赖.ps1
.\启动助手.ps1 -Demo  # 离线演示，不读取游戏、真实凭据或调用云服务
.\启动助手.ps1        # 正式运行，使用自己的 Key
```

也可手动建立虚拟环境：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install --no-deps -e .
.\.venv\Scripts\python.exe -m hots_chat.app --demo
```

Python 发行包名为 `hots-assistant`；源码模块和本机数据目录沿用 `hots_chat`、`HotsChatHelper`。

## 常见问题

**账号已验证，翻译仍失败**：身份验证只说明 Key 能识别账号，还需开通机器翻译通用版、授予翻译权限并保证账号服务可用。0.3.12 会显示失败阶段及安全错误类别；检查提示后再重试。

**没有中文译文**：确认自己的 Key 已连接、“自动翻译”已开启且频道筛选正确。当前接收翻译只支持英文和韩文，其他语言仅保留原文。

**返回大厅或换局后没消息**：先在游戏内发送一条普通聊天；仍不恢复可在“设置 → 连接”手动重新连接。独立战网客户端的聊天不在采集范围内。

**大厅昵称显示未知**：助手会尝试从已验证的同账号记录恢复昵称；无法确认身份时保留未知，不猜测其他玩家的名字。旧未知消息不自动补名。

**F8 没有效果**：确认游戏在前台、单独按 F8 并松开组合键；查看底部状态提示。可在“设置 → 快捷键”修改为 F1–F12。

**连按间隔怎么设置**：在“动作连按”选择 S 或 Y+S，填写“按键间隔”后点“保存并应用”，再回游戏按 F8。两种动作都能编辑，范围 20–5000 毫秒，分别保存，新配置均默认 20；旧版本保存过的 Y+S 间隔继续使用。S 填 100 表示每隔 100 毫秒按一次 S；Y+S 填 200 表示 Y → 等 200 毫秒 → S → 等 200 毫秒再循环。保存配置会结束当前动作，不会立即自动开始；实际节奏受 Windows 和游戏响应影响，卡顿不补发。

**如何反馈链路问题**：先到“设置 → 诊断”勾选“开启诊断日志”，复现问题后导出 ZIP，说明大致时间与操作。错译或表情问题可另勾详细诊断；它会记录限长聊天内容，分享前自行检查。关闭后不再记录新事件，已有日志仍可导出；下次启动仍默认关闭。完整密钥不进入日志，不要另行附带 `.env` 或 `credentials.dpapi`。

**自动首选天赋怎么用**：先在游戏里给想用的每层天赋标好爱心，保持“快速选择首选天赋”快捷键为 `Ctrl+反引号`（Esc 下方、数字 1 左边的键），在助手“天赋辅助”勾选开关后回游戏。偏好会保存，换局重新识别本地玩家；关闭后停止读取和发送。只向当前前台的目标游戏发送按键，不抢焦点，后台低频只读以观察换局。每层只尝试一次，3 秒未确认就提示手动处理；补爱心或改快捷键后，请手选本层，下一层继续检测。人工先选、短暂读取失败或关开功能不会触发同层重复发送。

**乱斗、其他英雄和英文支持到哪一步**：读取当前英雄目录中的真实解锁等级，克罗米使用 `1/2/5/8/11/14/18`；不靠中文名称、屏幕坐标或固定玩家槽。已在 build 98348 试用完成霍格多层手选对照、克罗米特殊层级对照、大厅退出再进、敌我镜像克罗米与友军归属读取，并实测克罗米一级由助手发送一次快捷键后自动选中。普通对局和乱斗的自然升级、连续多局及英文客户端尚待实机验收。禁用层和附加条件参与读取判断，最终首选由游戏处理，助手不替换不可选的爱心天赋。未知 build、身份或模式不发送；观战/回放未验收。50 毫秒是目标轮询间隔，实际选中时间受系统和游戏影响，不保证同一帧。回读确认表示该层已选择，助手没有独立读取当前爱心方案来核对特定目标。
